# Final Product Closure — Truth Boundary and Discovery Evidence Contract

## Purpose
This defines the release contract for Tiannara's research, simulated-world, immune, nervous-system, and discovery paths.

## Discovery admission
A candidate produced by Tiannara or a simulated world is not a discovery merely because a generator produced it.

Lifecycle:
1. Candidate generation
2. Exact provenance capture
3. Independent execution or simulation classification
4. Observation capture
5. Falsification / failure testing
6. Replication where applicable
7. ACL audit
8. OAVL adversarial/ontological audit
9. Mathematical consistency checks
10. Competing-explanation search
11. Epistemic classification
12. Only then: knowledge integration / reporting

## Required epistemic states
- UNKNOWN — insufficient evidence
- HYPOTHESIS — proposed explanation not yet validated
- SIMULATED_RESULT — result produced by a simulation and explicitly labeled as such
- SUPPORTED — evidence survives declared tests and reproduction requirements
- PROVEN_WITHIN_FORMAL_SYSTEM — formal proof succeeded within a declared formal system
- CONTESTED — material evidence conflicts
- REJECTED — falsified or invalidated
- REQUIRES_REVISION — tests expose unresolved defects

No confidence value may substitute for missing evidence.

## Discovery report
A reportable discovery must include the exact claim; origin; world/civilization and genome lineage; exact evidence IDs; experiment IDs; simulation configuration and seed; code/model/version identity; observations; controls; falsification tests; failures/inconclusive tests; replication results; mathematical checks; ACL result; OAVL result; competing explanations; limitations; unknowns; final epistemic state; provenance/cryptographic identity; and why the evidence supports that classification.

If evidence is insufficient, Tiannara must say so and schedule or propose the next stress test rather than upgrading the claim.

## Stress-testing rule
An important but uncertain theory should trigger adversarial testing: counterexamples, boundary conditions, parameter sensitivity, independent replay/reimplementation, alternative hypotheses, negative controls, perturbation tests, cross-world replication, mathematical invariants, and provenance integrity.

A failed stress test remains visible in the evidence chain.
