# MC-001 — Mathematics Substrate Reconciliation Protocol

**Gate:** MC-001 (Reconciliation Phase)
**Campaign:** Tiannara Remediation + Substrate Integration
**Class:** EVIDENCE COLLECTION + CLASSIFICATION (no mutation)
**Predecessors:** R0 ✅, AC-001 CERTIFIED (BOUNDED) ✅
**Mode:** OBSERVATIONAL
**Date:** 2026-08-27

## Objective

Determine, from actual repository evidence, whether Tiannara's mathematical
capabilities constitute a truthful, reusable, testable mathematical substrate.
Identify the minimum validated mutations required to establish that substrate.

## Governing Principle

Truth > apparent capability. Evidence > confidence. Verification > autonomy.
Reuse > duplication. Stable migration > broad rewrite.

## Critical Architectural Constraint (from AC-001)

Mathematics is an epistemic substrate, NOT a canonical application domain.
MC-001 must NOT:
- Create `:mathematics` as a canonical domain
- Reintroduce mathematics into the 20-domain ontology
- Create another mathematical domain registry
- Duplicate domain identity infrastructure
- Couple mathematical infrastructure to the domain registry

## Truth Classification Categories

REAL / PARTIAL / STRUCTURAL / THEATRICAL / BROKEN / DEAD / DUPLICATE / UNKNOWN

## Hard Stops

- No mathematical capability fabrication
- No theorem claimed proven without verification
- No generated formula treated as discovered without validation
- No benchmark mistaken for proof
- No prompt mistaken for mathematical infrastructure
- No mock mistaken for implementation (a `mock: true` tuple is NOT capability)
- No textual representation mistaken for verified symbolic representation
- Mathematics not reintroduced as canonical domain
- No production mutation without authorization
- No MC-002/MC-003/MC-004 work

## Evidence Method

All inventory entries are grounded in actual source inspection under
`lib/tiannara/` (see MC001-MATHEMATICS-CAPABILITY-INVENTORY.md for file/line
references). Where a claim is inference rather than inspected source, it is
marked UNKNOWN or flagged accordingly. No capability is asserted higher than
its evidence supports.

## Verdict Space

CERTIFIED / QUALIFIED_PARTIAL / NOT_CERTIFIED

A lack of mathematical capability is NOT itself a failure.
Incorrectly claiming capability exists IS a failure.
