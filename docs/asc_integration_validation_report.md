## Failure Analysis

### Failed Project (1/10)
**Project ID**: asc_test_0010  
**Goal**: "Create a log aggregation service. Ingest logs from multiple sources..."  
**Failure Reason**: `:no_test_contracts_generated`  

**Root Cause**: The Requirements Extractor found 0 invariants, 1 capability, 0 constraints. With only 1 capability and no invariants, the Testing phase generated only 1 unit test contract, which wasn't enough to trigger implementation (needs at least 1 contract to proceed).

**Fix**: Improve test goals to include stronger invariant language ("must", "cannot", "shall") or relax the guard condition in Testing Civilization to allow single-contract projects.
