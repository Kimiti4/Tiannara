## The Critical Risk: Feedback Loop Explosion

**Current loops (stable):**

```
Core → Domains → World Model → Feedback
```

**After Phase 6 (without metrics):**

```
Core → Domains → World Model → AEO → RAC → History → GRCC → ...
Plus: CIS loops, Metrics loops, Persistence loops, Ontology loops
```

**Potential:** Cascade failures from recursive effect interactions

**Solution:**

1. Add Metrics first (get visibility)
2. Add Circuit breakers (prevent runaway)
3. Add Rate limiting (bound changes)
4. Add Cascade detection (early warnings)

## The Major Insight: GRCC Integration

**Before:**


**After:**

```
GRCC lineages optimize for World Model quality improvement

```

This changes lineage specialization from random to purposeful.
