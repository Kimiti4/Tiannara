# 🔥 Important Concept

Templates should NEVER directly call domains.

Bad:

```text
Frontend → RE domain
```

Good:

```text
Frontend
   ↓
Workflow API
   ↓
Workflow Engine
   ↓
Domain Orchestrator
   ↓
Domains
```

Why?

Because later you can:

* swap domains
* add evolution
* add memory
* add optimization
* add autonomous improvement
* add caching
* add distributed execution

without changing the frontend.
