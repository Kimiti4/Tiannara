Based on the provided document, the integration of the 8 hyperintelligence upgrades is not meant to be done all at once in a "waterfall" approach. Attempting to do so would be "architecturally premature and computationally risky". Instead, they follow a "progressive, just-in-time deployment schedule," where each phase of the 7-Phase Post-REA roadmap acts as a vehicle that pulls in specific upgrades as they become necessary.

Here is how the phased integration is scheduled across the roadmap:

**1. The Immediate Bridge (Current Transition into Phase 1)**

* 
**Upgrade 7 (Epistemic Coarse-Graining)** & **Upgrade 8 (Distributed Validation):** These are actively being bridged into the system first. By building the Universal Causal Compiler (UCC) hook, the system natively executes the coarse-graining required to start **Phase 1: Institutional Evolution Engine**. (Note: Upgrade 8 also powers Phase 5: Discovery Mining by using the ecology as a theorem prover to validate discoveries via "Proof of Work" ).



**2. The Mid-Term Rollout (Phases 2, 3, and 4)**
Once institutions are successfully evolving in Phase 1, the next batch of upgrades is integrated to grant the system autonomy:

* **Phase 2: Constitutional Intelligence** is powered by **Upgrade 4 (Neuro-Symbolic Routing)**. This allows the system's router to safely tune constraints rather than micromanaging the agents.


* 
**Phase 3: Autonomous World Generation** utilizes **Upgrade 6 (Endogenous Causal Inference / Do-Calculus)** to allow Tiannara to run active interventional experiments by spinning up entirely new physics engines.


* 
**Phase 4: Meta-Civilizational Search** requires **Upgrade 2 (Active Epistemic Foraging)**, which uses the Free Energy Principle to hunt for civilizational designs that minimize the system's own uncertainty.



**3. The Endgame Integration (Phases 6 and 7)**
The final and most mathematically complex upgrades are reserved for the end, as they rely on a fully mature, multi-world ecology to function:

* **Phase 6: Cognitive Immune Systems** deploys **Upgrade 3 (Non-Monotonic Truth Maintenance)**. This integration uses a Justification-Based Truth Maintenance System (JTMS) to instantly retract conclusions based on false premises, thereby preventing hallucination cascades.


* 
**Phase 7: Recursive Ontology Evolution** integrates **Upgrade 1 (Higher-Order Topology)** and **Upgrade 5 (Vector-Symbolic Architectures)**. These are built strictly for this final phase, requiring the UCC to have already extracted thousands of concepts so the system can map them in high-dimensional vector spaces and invent entirely new symbols.



In short, you only need to finish the UCC Coarse-Graining hook you are currently working on to initiate Phase 1; Tiannara will naturally pull the remaining 7 upgrades into existence as it climbs the civilizational roadmap.
