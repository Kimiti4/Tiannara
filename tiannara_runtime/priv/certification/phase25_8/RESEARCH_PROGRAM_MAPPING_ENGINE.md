# Research Program Mapping Engine

## Purpose
Maps challenges to existing and proposed research programs — ensuring challenges are addressed within coherent program structures.

## Program Types

### Existing Research Programs
- Active scientific research initiatives
- Engineering development programs
- Cross-disciplinary programs
- International collaborations

### Proposed Programs
- Programs suggested by challenge routing
- New program proposals
- Program modifications

### Program Hierarchy
- Programs contain sub-programs
- Programs align with domains
- Programs have lifecycles

## Mapping Process

### Challenge-to-Program Matching
- Score each challenge against active programs
- Identify best-fit programs
- Flag challenges without good program fit
- Propose new programs for orphan challenges

### Program Portfolio Analysis
- Coverage: what fraction of challenges are addressed?
- Gaps: which domains lack program coverage?
- Balance: is portfolio balanced across domains and challenge types?
- Overlap: are there redundant programs?

### Program Evolution
- Programs evolve as challenges are solved
- New programs form to address emerging challenge clusters
- Programs retire when their challenges are resolved

## Output
Challenge-program mappings, program portfolio analysis, coverage gaps, new program proposals, portfolio balance metrics.
