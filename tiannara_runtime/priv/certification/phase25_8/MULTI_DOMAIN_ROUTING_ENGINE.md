# Multi-Domain Routing Engine

## Purpose
Routes challenges that span multiple scientific and engineering domains — the most important challenges are rarely confined to a single discipline.

## Multi-Domain Challenge Types

### Interdisciplinary Science
- Challenge requires multiple scientific disciplines (e.g., climate change requires physics, chemistry, biology, economics)
- Route to each relevant discipline
- Coordinate interdisciplinary research programs

### Science-to-Engineering
- Discovery must be translated to engineering capability
- Route through both scientific and engineering pipelines
- Coordinate transition from discovery to application

### Engineering-to-Science
- Engineering challenge reveals scientific question
- Route back through scientific pipeline
- Close the loop

### Cross-Domain Bottleneck
- Bottleneck in one domain blocks progress in others
- Identify all blocked domains
- Prioritize bottleneck resolution

## Coordination Mechanisms

### Joint Routing
- Challenge assigned to multiple domains simultaneously
- Primary and secondary domain designations
- Cross-domain leads identified

### Dependency Coordination
- Multi-domain challenges have internal dependencies
- Sequence dependent work across domains
- Synchronize timelines

### Integration
- Cross-domain results must be integrated
- Designate integration point
- Ensure compatibility across domains

## Output
Multi-domain routing plan: domains involved, coordination structure, dependency sequencing, integration point, timeline.
