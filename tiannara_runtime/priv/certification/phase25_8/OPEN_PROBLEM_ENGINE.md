# Open Problem Engine

## Purpose
Manages the set of open (unsolved) problems that represent the frontier of human knowledge — the most important unsolved questions across all domains.

## Problem Categories

### Scientific Open Problems
- What is dark matter?
- What is dark energy?
- How does quantum gravity work?
- What is the nature of consciousness?
- Is there extraterrestrial life?
- Can we unify physics?
- What is the origin of life?

### Engineering Open Problems
- How do we achieve practical fusion energy?
- How do we build a space elevator?
- How do we achieve human-level AI safely?
- How do we reverse climate change?
- How do we achieve sustainable space colonization?

### Civilizational Open Problems
- How do we achieve global cooperation?
- How do we manage existential risks?
- How do we create sustainable prosperity for all?
- How do we govern advanced AI?
- How do we preserve freedom in a technologically advanced society?

## Problem Representation
Each open problem: canonical statement, history, current state of knowledge, main competing approaches, key evidence, key knowledge gaps, related challenges in the registry, progress metrics, leading researchers/institutions, predicted resolution timeline (with uncertainty).

## Progress Tracking
- Change in understanding over time
- Milestones achieved
- Failed approaches and lessons
- Shifting consensus
- Emerging new approaches

## Output
Open problem catalog with status, progress history, competing approaches, key evidence, uncertainty assessment, predicted resolution timeline.
