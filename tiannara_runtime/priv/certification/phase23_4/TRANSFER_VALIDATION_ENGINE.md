# Transfer Validation Engine

## Purpose

Validate candidate transfers across multiple compatibility dimensions.
Every transfer must pass constitutional validation before integration.

## Validation Dimensions

| Dimension | Check |
|-----------|-------|
| Semantic | Concepts map correctly across domains |
| Causal | Causal mechanisms are consistent |
| Evidence | Supporting evidence transfers appropriately |
| Prediction | Predictions remain valid in target domain |
| Engineering | Engineering constraints are satisfied |
| Constitutional | No constitutional principles violated |

## Validation Outcomes

| Outcome | Meaning |
|---------|---------|
| Approved | Transfer is valid and can proceed |
| Rejected | Transfer is invalid; documented with reason |
| Requires Adaptation | Transfer is valid with modifications |
| Unknown | Insufficient evidence to determine |
| Deferred | Validation postponed pending new evidence |

## Validation Record

Each validation records:
- Transfer candidate ID
- Per-dimension results
- Overall outcome
- Justification
- Evidence references
- Validator engine and version
- Timestamp and fingerprint
