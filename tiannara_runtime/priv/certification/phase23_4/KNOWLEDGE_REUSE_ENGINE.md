# Knowledge Reuse Engine

## Purpose

Track how transferred knowledge is reused across domains, measuring
frequency, success rate, cross-domain impact, and long-term value.

## Tracked Metrics

| Metric | Description |
|--------|-------------|
| Reuse Frequency | How often a knowledge artifact is referenced or applied |
| Reuse Success | Success rate when the artifact is used in new contexts |
| Cross-Domain Impact | Number of domains where the artifact has been applied |
| Engineering Benefit | Quantified improvement in engineering outcomes |
| Scientific Benefit | Contribution to new discoveries or theory refinement |
| Knowledge Lifespan | Time from initial transfer to last successful reuse |

## Reuse Record

Each reuse event records:
- Source knowledge artifact ID
- Target context (domain + specific application)
- Reuse outcome (success, partial, failure)
- Adaptation applied (if any)
- Timestamp
- Evidence of impact

## Constitutional Rules

- Reuse metrics are transparent and auditable
- Failed reuses are as important as successful ones
- Low-reuse knowledge is preserved, not pruned
