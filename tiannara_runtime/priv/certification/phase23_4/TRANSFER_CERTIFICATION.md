# Transfer Certification

## Purpose

Certify that transfers meet constitutional requirements before integration.

## Certification Checks

| Check | Description |
|-------|-------------|
| Semantic Integrity | Mapping preserves meaning across domains |
| Causal Consistency | Causal structure is preserved |
| Evidence Integrity | Source evidence is uncorrupted |
| Adaptation Validity | All translation decisions are justified |
| Replayability | Transfer can be replayed deterministically |
| Provenance Completeness | Full lineage is recorded |
| Uncertainty Quantification | All uncertainties have bounds |
| Constitutional Compliance | No constitutional violations |

## Certification Levels

| Level | Meaning |
|-------|---------|
| Candidate | Initial candidate, not yet validated |
| Validated | Passed validation checks, awaiting adaptation |
| Adapted | Adapted for target domain, awaiting integration |
| Integrated | Fully integrated into target domain knowledge |
| Superseded | Superseded by a more comprehensive transfer |
| Retired | No longer actively used, archaeologically preserved |

## Certificate Structure

Each certificate records:
- Transfer candidate ID
- Certification level
- Per-check results
- Timestamp
- Fingerprint (content hash)
- Certifying engine version
