# Transfer Report

## Purpose

Generate comprehensive reports on the state of cross-domain knowledge
transfer for observation, analysis, and decision-making.

## Report Types

| Report | Content |
|--------|---------|
| Transfer Summary | All active transfers and their status |
| Cross-Domain Graph | Current connections between domains |
| Knowledge Flow Report | Which knowledge is flowing between which domains |
| Analogy Network | Active analogies and their evidence |
| Transfer Success Report | Success/failure rates by domain pair |
| Knowledge Reuse Report | Reuse frequency and impact |
| Cross-Domain Principles Catalog | All generalized principles |
| Engineering Impact Report | Quantified engineering benefits |
| Transfer Priority Report | Current ranking of pending candidates |
| Transfer Uncertainty Report | Confidence assessment across all transfers |

## Report Properties

- All reports are deterministic (same state → same report)
- Reports include machine-readable and human-readable formats
- Reports are time-stamped and archiveable
- Reports can be generated for any point in the replay timeline
