# Transfer Priority Engine

## Purpose

Rank transfer candidates by scientific value, engineering utility, novelty,
cross-domain reach, information gain, prediction improvement, risk, and
constitutional benefit. Priority remains explainable.

## Priority Dimensions

| Dimension | Weight Direction |
|-----------|-----------------|
| Scientific Value | Higher = more valuable |
| Engineering Utility | Higher = more useful |
| Novelty | Higher = more novel |
| Cross-Domain Reach | Higher = affects more domains |
| Information Gain | Higher = more new information |
| Prediction Improvement | Higher = better predictions |
| Risk | Lower = safer |
| Transfer Cost | Lower = cheaper to transfer |
| Constitutional Benefit | Higher = more aligned with principles |

## Priority Calculation

Each candidate receives a multi-dimensional priority vector. No single
aggregate score — different stakeholders may weight dimensions differently.

## Transparency

- Priority contributions are decomposed per dimension
- Dimension scores reference supporting evidence
- Priority recalculations are recorded and explainable
