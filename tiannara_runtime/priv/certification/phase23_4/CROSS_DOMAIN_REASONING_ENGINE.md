# Cross-Domain Reasoning Engine

## Purpose

Reason over multiple domains simultaneously, supporting domain intersection,
composition, analogy, contradiction, synthesis, and evolution.

## Reasoning Modes

| Mode | Description |
|------|-------------|
| Domain Intersection | Find knowledge common to multiple domains |
| Domain Composition | Combine knowledge from multiple domains for new purposes |
| Domain Analogy | Reason by analogy between domain structures |
| Domain Contradiction | Identify where domains make incompatible claims |
| Domain Synthesis | Create new domain knowledge from cross-domain combination |
| Domain Evolution | Track how domains change through cross-domain influence |

## Reasoning Properties

- All reasoning is evidence-backed
- All reasoning steps are recorded and replayable
- Cross-domain conclusions are marked with appropriate uncertainty
- Reasoning can be reviewed and critiqued constitutionally

## Applications

- Suggesting novel hypotheses from cross-domain patterns
- Identifying gaps in domain knowledge visible only from outside
- Predicting how a known phenomenon might manifest in a new domain
- Designing experiments informed by multiple domain perspectives
