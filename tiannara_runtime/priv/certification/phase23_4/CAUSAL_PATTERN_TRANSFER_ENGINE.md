# Causal Pattern Transfer Engine

## Purpose

Identify and transfer reusable causal patterns — feedback loops, emergence,
self-organization, resilience, adaptation, control hierarchies, and causal
motifs — across domains.

## Transferable Causal Patterns

| Pattern | Description |
|---------|-------------|
| Feedback Loops | Positive and negative feedback structures |
| Emergence | Macroscopic properties arising from microscopic interactions |
| Self-Organization | Spontaneous order without external control |
| Resilience | Ability to maintain function under perturbation |
| Adaptation | Systematic adjustment to changing conditions |
| Control Hierarchies | Nested levels of regulation and feedback |
| Causal Motifs | Recurring small causal graph structures |

## Transfer Process

1. Extract causal graph from source domain mechanism
2. Abstract the causal pattern to its essential structure
3. Map causal nodes and edges to target domain semantics
4. Verify causal consistency in target domain
5. Adapt for domain-specific constraints
6. Register as a transferred causal pattern

## Constitutional Rules

- Causal patterns require evidence, not structural similarity alone
- Disanalogies in causal structure are documented
- Causal claims are provisional until empirically validated
