# Engineering Decision Hierarchy

## Purpose

Define the hierarchy and authority for engineering decisions within the constitutional framework.

## Decision Levels

| Level | Authority | Scope |
|---|---|---|
| Constitutional | Constitution | All engineering |
| Strategic | Engineering Council | Civilization-scale |
| Program | Program Manager | Multi-project programs |
| Project | Project Lead | Single projects |
| Technical | Engineering Lead | Technical decisions |
| Operational | Operations | Day-to-day operations |

## Decision Types

- **Technology Selection** — Which technologies to develop/deploy.
- **Resource Allocation** — How engineering resources are distributed.
- **Priority Setting** — Which programs/projects take precedence.
- **Certification** — Whether engineering artifacts meet standards.
- **Escalation** — When to escalate decisions upward.
- **Evolution** — When and how to evolve engineering systems.

## Decision Recording

Every decision records:
- Decision maker
- Decision rationale
- Alternatives considered
- Constitutional constraints applied
- Evidence supporting decision
- Expected civilizational benefit
- Actual outcome (post-hoc)

## Replay Support

All decisions are replayable:
- Decision state captured before decision.
- Decision output captured after decision.
- Deterministic replay reproduces same decision given same inputs.
