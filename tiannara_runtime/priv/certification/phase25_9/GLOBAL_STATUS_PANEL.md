# Global Status Panel

## Purpose
The primary mission control panel — shows the overall health of Tiannara's runtime, scientific, engineering, planetary, and civilizational systems.

## Displays

### Constitutional Health
- Constitutional compliance status (all engines)
- Active constitutional violations (if any)
- Pending constitutional reviews
- Constitutional evolution status

### Runtime Health
- CPR runtime status
- Replay integrity status
- Certification status across all engines
- Archaeology integrity status

### System Health
- All Phase 25 engines status (online/offline/error)
- Data pipeline health
- Storage system health
- Compute utilization

### Active Incidents
- Current alerts by severity
- Active emergency protocols
- Ongoing interventions (from CPISE)
- Unresolved anomalies

### Quick Summary
- Discoveries today
- Active challenges
- Critical risks
- Resource stress indicators
- Civilizational trajectory indicators

## Data Sources
- CPR runtime metrics
- Certification certificates
- Alert engine
- All Phase 25 engine health endpoints

## Refresh
- Real-time for critical metrics
- 5-second for status indicators
- 30-second for summary statistics
