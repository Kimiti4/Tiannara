# Discovery Challenge Panel

## Purpose
Shows the state of the discovery challenge system — active challenges, solved challenges, knowledge gaps, and research pipeline.

## Displays

### Active Challenges
- Current challenge queue by priority
- Status distribution (identified, classified, routed, in_progress, under_review)
- Challenges by domain
- Recently identified challenges
- Recently solved challenges

### Solved Challenges
- Historical solved challenges
- Discovery scores and value
- Solved challenge impact
- Archive access

### Research Queue
- Challenge queue by priority
- Queue wait times
- Bottleneck analysis
- Resource constraints affecting queue

### Knowledge Gaps
- Gap map by domain
- Gap closure progress
- Newly identified gaps
- Gap priority ranking

### Discovery ROI
- Scientific return vs. investment
- ROI by domain
- Comparative analysis
- Efficiency trends

### Pipeline Status
- End-to-end pipeline health
- Stage throughput
- Bottleneck identification
- Cycle time analysis

## Data Sources
- CDCIE (Phase 25.8) — challenge registry and pipeline
