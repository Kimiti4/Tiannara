# Digital Twin Panel

## Purpose
Shows the state of the constitutional planetary digital twin — its synchronization, layer health, confidence, and active scenarios.

## Displays

### Twin Synchronization
- Twin sync status (in_sync, lagging, desynced)
- Sync latency
- Last sync timestamp
- Sync errors and resolution

### Layer Health
- All 12 twin layer statuses (geosphere, atmosphere, hydrosphere, biosphere, population, infrastructure, economic, energy, agriculture, technology, scientific capability, governance)
- Layer confidence scores
- Layer data freshness
- Layer model accuracy

### Active Scenarios
- Active simulation scenarios
- Scenario purpose and trigger
- Scenario progress
- Scenario confidence

### Scenario Divergence
- How much do active scenarios diverge?
- Critical divergence points
- Scenario comparison metrics

### Twin Confidence
- Overall twin confidence
- Confidence by layer and region
- Confidence trend
- Key uncertainty contributors
- Data gaps affecting confidence

### Twin Evolution
- Twin accuracy improvement over time
- Model calibration events
- New data sources integrated
- Resolution improvements

## Data Sources
- CPDT (Phase 25.3) — digital twin engine
