# Alternative Explanation Engine

## Purpose

Generate competing explanations for findings presented in scientific artifacts. Every finding may have multiple interpretations, and alternative explanations become permanent scientific evidence.

## Alternative Types

| Type | Description |
|------|-------------|
| Better Explanation | Accounts for more evidence with fewer assumptions |
| Equivalent Explanation | Accounts for same evidence with different mechanism |
| Weaker Explanation | Accounts for subset of evidence |
| Insufficient Evidence | No alternative can be evaluated without more data |
| Unknown | No alternative explanation identified |

## Generation Process

1. Analyze the artifact's causal claims
2. Search for alternative causal structures consistent with the evidence
3. Evaluate each alternative against the evidence
4. Score alternatives by explanatory power
5. Document each alternative with supporting reasoning

## Constitutional Rules

- Alternative explanations are preserved permanently
- The existence of alternatives does not invalidate the original claim
- Alternatives must be considered before certification
- The original author can respond to alternatives
