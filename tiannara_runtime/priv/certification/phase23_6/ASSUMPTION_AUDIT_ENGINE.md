# Assumption Audit Engine

## Purpose

Identify all assumptions underlying a scientific artifact — explicit, implicit, unsupported, obsolete, or cross-domain — and track them constitutionally.

## Assumption Types

| Type | Description |
|------|-------------|
| Explicit | Assumptions stated by the artifact author |
| Implicit | Assumptions required but not stated |
| Unsupported | Assumptions lacking evidentiary support |
| Obsolete | Assumptions contradicted by newer evidence |
| Cross-Domain | Assumptions imported from another domain |
| Hidden | Assumptions discovered by reviewers |

## Audit Process

1. Extract explicit assumptions from artifact
2. Infer implicit assumptions from methodology and reasoning
3. Evaluate each assumption against available evidence
4. Flag unsupported and potentially obsolete assumptions
5. Cross-reference assumptions across domains
6. Produce assumption audit report

## Constitutional Rules

- All assumptions must be explicitly documented
- Unsupported assumptions must be flagged
- Assumptions are tracked and versioned
- Assumption changes trigger re-review
