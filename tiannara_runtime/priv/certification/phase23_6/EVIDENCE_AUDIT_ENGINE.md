# Evidence Audit Engine

## Purpose

Verify that scientific artifacts are supported by complete, high-quality, relevant, and diverse evidence. No unsupported conclusion is accepted.

## Audit Dimensions

| Dimension | Check |
|-----------|-------|
| Evidence Completeness | Is all evidence that should be present actually present? |
| Evidence Quality | Does the evidence meet quality thresholds? |
| Evidence Relevance | Does the evidence actually support the claimed conclusions? |
| Evidence Diversity | Does the evidence come from multiple independent sources? |
| Missing Evidence | What evidence is absent that would be expected? |
| Conflicting Evidence | What evidence contradicts the conclusions? |

## Audit Process

1. Compile list of all evidence referenced by the artifact
2. Verify each evidence item exists and is uncorrupted
3. Assess quality of each evidence item
4. Evaluate relevance of each evidence item to each claim
5. Search for missing evidence that would be expected
6. Search for conflicting evidence
7. Produce evidence audit report

## Audit Outcomes

| Outcome | Meaning |
|---------|---------|
| Evidence Sufficient | All claims adequately supported |
| Evidence Partial | Some claims insufficiently supported |
| Evidence Insufficient | Critical claims lack support |
| Evidence Conflicting | Significant conflicting evidence exists |
