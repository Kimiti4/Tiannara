# Statistical Audit Engine

## Purpose

Evaluate the statistical validity of scientific artifacts: sample size, statistical assumptions, confidence intervals, power, uncertainty, effect size, and error propagation.

## Audit Dimensions

| Dimension | Evaluation |
|-----------|------------|
| Sample Size | Is the sample adequate for the statistical claims? |
| Statistical Assumptions | Are normality, independence, homoscedasticity verified? |
| Confidence Intervals | Are CIs reported and appropriately interpreted? |
| Statistical Power | Is the study adequately powered? |
| Uncertainty | Are all uncertainties quantified? |
| Effect Size | Are effect sizes reported beyond p-values? |
| Error Propagation | Are errors properly propagated through calculations? |
| Multiple Comparisons | Are multiple comparison corrections applied? |

## Audit Process

1. Extract statistical methodology from artifact
2. Verify statistical assumptions against data characteristics
3. Evaluate effect size reporting
4. Assess uncertainty quantification
5. Check for common statistical errors
6. Produce statistical audit report

## Constitutional Rules

- Statistical significance is not scientific significance
- Effect sizes must be reported alongside p-values
- Uncertainty must be quantified for all reported values
