# Peer Review Certification

## Purpose

Certify that reviewed artifacts meet constitutional standards. Certification is the final gate before knowledge integration.

## Certification Checks

| Check | Description |
|-------|-------------|
| Evidence Audit Passed | Evidence sufficient and verified |
| Methodology Audit Passed | Methodology sound |
| Statistical Audit Passed | Statistical analysis valid |
| Bias Assessment Complete | Biases identified and documented |
| Alternative Explanations Considered | Alternatives evaluated |
| Reproducibility Assessed | Reproducibility level recorded |
| Objections Resolved | All objections addressed |
| Constitutional Compliance | No constitutional violations |

## Certification Levels

| Level | Meaning |
|-------|---------|
| Certified | All checks passed, artifact accepted |
| Provisionally Certified | Minor issues identified, conditional acceptance |
| Requires Revision | Issues identified, revision needed |
| Requires Replication | Key claims need independent confirmation |
| Not Certified | Rejected on constitutional grounds |

## Certificate Structure

Each certificate records:
- Artifact ID
- Certification level
- Per-check results with evidence references
- Review IDs that informed the certification
- Timestamp
- Fingerprint (content hash)
