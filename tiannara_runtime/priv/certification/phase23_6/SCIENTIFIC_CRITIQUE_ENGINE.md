# Scientific Critique Engine

## Purpose

Produce comprehensive constitutional critiques of scientific artifacts across multiple consistency dimensions. Every criticism references supporting evidence.

## Critique Dimensions

| Dimension | Evaluation |
|-----------|------------|
| Logical Consistency | Do conclusions follow from premises without contradiction? |
| Causal Consistency | Are claimed causal relationships justified? |
| Empirical Consistency | Do claims match observed evidence? |
| Engineering Consistency | Are engineering constraints satisfied? |
| Cross-Domain Consistency | Do claims cohere with knowledge from other domains? |
| Constitutional Consistency | Does the artifact comply with constitutional rules? |

## Critique Structure

Each critique records:
- Artifact ID
- Per-dimension assessment with evidence
- Overall assessment
- Strengths identified
- Weaknesses identified
- Missing elements
- Recommended improvements
- Critic confidence
- Reviewer ID

## Constitutional Rules

- Every criticism cites supporting evidence
- Criticisms are independent of artifact origin
- Criticisms are themselves reviewable
- No criticism can be suppressed
