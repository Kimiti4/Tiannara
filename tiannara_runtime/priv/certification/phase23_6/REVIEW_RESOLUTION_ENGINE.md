# Review Resolution Engine

## Purpose

Determine the final outcome of a peer review based on critiques, consensus, and constitutional rules.

## Possible Outcomes

| Outcome | Meaning |
|---------|---------|
| Accept | Artifact meets constitutional standards |
| Minor Revision | Minor issues that do not affect core claims |
| Major Revision | Substantial issues requiring changes |
| Replicate | Key claims require independent replication |
| Reject | Artifact does not meet constitutional standards |
| Insufficient Evidence | Cannot evaluate without more evidence |
| Unknown | Review inconclusive |

## Resolution Process

1. Receive critiques from all reviewers
2. Receive consensus from Review Consensus Engine
3. Evaluate outcomes against constitutional criteria
4. Select outcome deterministically
5. Document justification for outcome
6. Notify artifact author
7. Archive resolution with full lineage

## Constitutional Rules

- Resolution must reference supporting evidence
- Resolution is appealable with new evidence
- Resolution is permanently recorded
- Rejected artifacts remain archaeologically preserved
