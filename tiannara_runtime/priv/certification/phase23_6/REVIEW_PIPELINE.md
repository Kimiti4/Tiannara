# Review Pipeline

## Purpose

Define the deterministic, staged pipeline through which every scientific artifact passes for constitutional peer review.

## Pipeline Stages

```
1. Submission — Artifact enters review queue
2. Reviewer Assignment — Independent reviewers selected
3. Evidence Audit — Evidence completeness and quality verified
4. Methodology Review — Experimental design and controls evaluated
5. Assumption Analysis — All assumptions explicitly identified
6. Bias Analysis — Systematic bias detection
7. Alternative Explanations — Competing explanations generated
8. Reproducibility Assessment — Reproducibility verified
9. Scientific Critique — Comprehensive critique produced
10. Consensus — Multiple reviewer judgments aggregated
11. Certification — Artifact certified or returned for revision
12. Knowledge Feedback — Results fed back to knowledge ecosystem
```

## Stage Properties

- Each stage produces deterministic output from its inputs
- Stages can request additional information from the artifact author
- Stages can be re-run if new evidence becomes available
- The pipeline produces a complete review record at each stage
- Pipeline execution is fully replayable

## Pipeline Governance

- Stages are constitutionally mandated
- Stage order is fixed
- Skipping stages requires constitutional override
- Pipeline state is persisted for replay
