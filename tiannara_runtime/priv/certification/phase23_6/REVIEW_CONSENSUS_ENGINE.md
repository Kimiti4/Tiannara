# Review Consensus Engine

## Purpose

Aggregate judgments from multiple independent reviewers into a constitutional consensus. Consensus never suppresses minority opinions.

## Aggregation Methods

| Method | Description |
|--------|-------------|
| Unanimous | All reviewers agree |
| Majority | Most reviewers agree |
| Weighted | Weighted by reviewer expertise/credibility |
| Structured | Agreement per dimension rather than overall |
| Dissensus | Record all opinions when no consensus exists |

## Consensus Outputs

Each consensus record:
- Artifact ID
- Aggregation method used
- Number of reviewers
- Per-dimension agreement levels
- Overall recommendation
- Dissenting opinions (preserved verbatim)
- Confidence in consensus

## Constitutional Rules

- Consensus never suppresses minority opinions
- Dissenting opinions are preserved permanently
- Consensus method is transparent and deterministic
- Consensus is revisable with new evidence or reviewers
