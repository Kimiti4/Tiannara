# Replication Priority Engine

## Purpose

Rank discoveries requiring independent replication based on scientific importance, engineering impact, uncertainty, controversy, societal importance, and resource cost.

## Priority Dimensions

| Dimension | Weight Direction |
|-----------|-----------------|
| Scientific Importance | Higher = more foundational |
| Engineering Impact | Higher = more practical value |
| Uncertainty | Higher = less certain, more need |
| Controversy | Higher = more contested |
| Societal Importance | Higher = greater public impact |
| Resource Cost | Lower = cheaper to replicate |

## Replication Recommendations

Each recommendation records:
- Original discovery ID
- Recommended replication type (direct, conceptual, computational)
- Priority score
- Priority dimension breakdown
- Recommended methodology for replication
- Estimated resource requirements
- Status (pending, in_progress, completed, superseded)

## Constitutional Rules

- Replication priority is transparent and explainable
- Priority is revisable as new evidence emerges
- High-priority replications are constitutionally encouraged
- Failed replications are as valued as successful ones
