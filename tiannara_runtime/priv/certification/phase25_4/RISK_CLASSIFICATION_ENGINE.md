# Risk Classification Engine

## Purpose

Define the engine that classifies detected risks into a constitutional taxonomy.

## Risk Categories

| Category | Examples |
|---|---|
| Climate | Extreme weather, sea level rise, heatwaves |
| Geological | Earthquakes, volcanoes, tsunamis, landslides |
| Ecological | Ecosystem collapse, biodiversity loss |
| Biodiversity | Species extinction, habitat destruction |
| Food | Crop failure, supply chain disruption, famine |
| Water | Drought, flooding, contamination, scarcity |
| Energy | Grid failure, fuel shortage, blackouts |
| Health | Pandemic, epidemic, antimicrobial resistance |
| Infrastructure | Bridge failure, dam failure, building collapse |
| Transportation | Port closure, airspace shutdown, rail disruption |
| Communications | Internet outage, satellite failure, cable break |
| Economy | Recession, inflation, debt crisis, market crash |
| Manufacturing | Supply chain disruption, factory closure |
| Cybersecurity | Data breach, ransomware, critical system attack |
| Scientific Capacity | Lab closure, research funding loss |
| Engineering Capacity | Engineering workforce shortage |
| Governance | Political instability, institutional failure |
| Space Environment | Solar flare, asteroid, space debris |

## Classification Dimensions

Every risk is classified by:
- **Domain** — Which planetary domain(s) affected.
- **Type** — Natural, technological, economic, social, systemic.
- **Severity** — Minor, moderate, severe, catastrophic.
- **Probability** — Remote, unlikely, possible, likely, very likely.
- **Timeframe** — Immediate, short-term (1yr), medium (5yr), long (20yr), century (100yr).
- **Geographic Scope** — Local, regional, national, continental, global.
- **Confidence** — Level of evidence supporting assessment.

## Unknown Risk Handling

- Observations that don't match known risk patterns preserved for analysis.
- Unknown risks tracked and monitored for pattern emergence.
- Unknown risk metadata preserved in replay log.
- Unknown risks reported to observatory.
