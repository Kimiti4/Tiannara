# Root Cause Engine

## Purpose

Determine the constitutional root cause of every engineering failure. Root cause analysis is systematic, evidence-based, and fully replayable.

## Root Cause Methods

| Method | Description |
|--------|-------------|
| 5 Whys | Iterative questioning to find root cause |
| Fishbone Diagram | Categorize potential causes |
| Fault Tree Analysis | Top-down logical analysis |
| Event Tree Analysis | Bottom-up consequence analysis |
| Change Analysis | Identify what changed before failure |
| Barrier Analysis | Identify failed safeguards |

## Root Cause Properties

- Each root cause is supported by evidence
- Root cause analysis is fully replayable
- Root cause determinations are constitutionally reviewed
- Root cause history drives systemic improvements
- Corrective actions are verified for effectiveness
