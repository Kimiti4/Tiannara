# Decision Escalation Engine

## Purpose

Govern escalation of engineering decisions through constitutional levels. Every escalation is replayable.

## Escalation Levels

| Level | Scope |
|-------|-------|
| Project | Decisions within a single project |
| Program | Decisions affecting an entire program |
| Portfolio | Decisions affecting the portfolio |
| Engineering Council | Major engineering policy decisions |
| Constitutional Governance | Decisions affecting constitutional principles |

## Escalation Triggers

- Resource conflict between programs
- Schedule impact affecting portfolio
- Safety or constitutional concern
- Requirement change with broad impact
- Risk exceeding threshold
- Decision beyond delegated authority

## Escalation Properties

- Escalation paths are defined and transparent
- Escalation decisions are recorded with rationale
- Escalation history is fully preserved
- Escalation is fully replayable
