# Engineering Priority Engine

## Purpose

Set constitutional priorities across the engineering portfolio. Priority is the primary driver of resource allocation.

## Priority Factors

| Factor | Description |
|--------|-------------|
| Strategic Alignment | How well does the program serve constitutional goals? |
| Civilizational Benefit | What is the long-term civilizational value? |
| Urgency | How time-sensitive is the program? |
| Dependencies | How many other programs depend on this? |
| Risk | What is the risk of delay or cancellation? |
| Feasibility | Can the program succeed with available resources? |
| Readiness | Is the technology/infrastructure ready? |

## Priority Properties

- Priority is determined constitutionally
- Priority is dynamic — it changes with new information
- Priority decisions are fully explainable
- Priority history is fully preserved
- Priority is fully replayable
- Competing priorities are explicitly compared
