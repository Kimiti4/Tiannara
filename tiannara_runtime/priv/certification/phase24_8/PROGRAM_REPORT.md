# Program Report

## Purpose

Generate comprehensive reports on engineering program management for observation, analysis, and constitutional oversight.

## Report Types

| Report | Content |
|--------|---------|
| Portfolio Summary | Portfolio composition, balance, health |
| Program Report | Program status, milestones, risks, resources |
| Project Report | Project status, deliverables, schedule |
| Resource Report | Resource allocation, utilization, conflicts |
| Milestone Report | Milestone status across all programs |
| Risk Report | Portfolio-level risk assessment |
| Capacity Report | Engineering capacity, utilization, bottlenecks |
| Priority Report | Program priorities and ranking |
| Certification Report | Certification status across portfolio |
| Metrics Report | All program management metrics |
