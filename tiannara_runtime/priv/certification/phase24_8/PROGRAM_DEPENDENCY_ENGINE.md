# Program Dependency Engine

## Purpose

Map and manage dependencies between programs, projects, and engineering activities.

## Dependency Types

| Type | Description |
|------|-------------|
| Technology Dependency | Program depends on technology from another program |
| Resource Dependency | Programs share limited resources |
| Schedule Dependency | One program's output is input to another |
| Knowledge Dependency | Program requires knowledge from another |
| Infrastructure Dependency | Programs share infrastructure |
| Verification Dependency | Programs share verification resources |

## Dependency Properties

- Dependencies are explicitly modeled
- Dependency criticality is quantified
- Dependency conflicts are detected and resolved
- Dependency changes are recorded
- Dependency graphs are fully replayable
