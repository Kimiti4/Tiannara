# Program Archaeology Model

## Purpose

Reconstruct the complete history of engineering program management: why programs were initiated, why priorities shifted, how resources were allocated, and the complete management lineage.

## Reconstructable Questions

- Why was this program initiated?
- Why did program priorities shift?
- How were resources allocated across programs?
- Why was a program restructured or terminated?
- What was the complete management lineage of a program?

## Archaeological Queries

| Query | Description |
|-------|-------------|
| ProgramOrigin(program_id) | Why and how a program was created |
| PriorityHistory(portfolio_id) | How priorities changed over time |
| ResourceAllocationHistory(resource_type) | How resources were allocated |
| ProgramTerminationRationale(program_id) | Why a program was terminated |
| ManagementLineage(program_id) | Complete ancestry of management decisions |

## Preservation

- All program management events are permanently preserved
- Archaeology operates on the same event log as replay
