# Engineering Portfolio Engine

## Purpose

Govern the complete engineering portfolio — all programs, projects, technologies, infrastructures, and engineering activities under constitutional management.

## Portfolio Types

| Portfolio | Content |
|-----------|---------|
| Research Portfolio | Scientific research programs |
| Technology Portfolio | Technology development programs |
| Engineering Portfolio | Engineering design and build programs |
| Manufacturing Portfolio | Production and manufacturing programs |
| Infrastructure Portfolio | Infrastructure programs |
| Deployment Portfolio | Deployment and operations programs |
| Operations Portfolio | Ongoing operational activities |

## Portfolio Properties

- Portfolios are constitutionally governed
- Portfolio composition is continuously visible
- Portfolio changes are recorded with rationale
- Portfolio history is fully preserved
- Portfolios are fully replayable
- Portfolio balance metrics are continuously tracked
