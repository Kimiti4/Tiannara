# Program Observability Model

## Purpose

Provide full observability into engineering program management. Integrate with the Tiannara Observatory.

## Observable Metrics

| Metric | Description |
|--------|-------------|
| Portfolio Health | Overall portfolio status, balance, risk |
| Active Programs | Count, status, phase distribution |
| Project Network | Program-project dependency graph |
| Milestone Progress | Milestones completed, in progress, overdue |
| Resource Allocation | Resource distribution across programs |
| Engineering Capacity | Current utilization, available capacity |
| Risk Dashboard | Portfolio risk exposure, top risks |
| Certification Progress | Certification status across portfolio |
| Executive Readiness | Overall engineering readiness level |
