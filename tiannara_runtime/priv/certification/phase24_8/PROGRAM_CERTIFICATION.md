# Program Certification

## Purpose

Certify that engineering programs, projects, and portfolio decisions meet constitutional standards.

## Certification Types

| Type | Description |
|------|-------------|
| Program Certification | Program meets constitutional standards |
| Project Certification | Project meets program requirements |
| Milestone Certification | Milestone criteria are satisfied |
| Deliverable Certification | Deliverable meets acceptance criteria |
| Portfolio Certification | Portfolio balance meets targets |
| Resource Certification | Resource allocation is constitutional |

## Certification Checks

| Check | Description |
|-------|-------------|
| Constitutional Alignment | Program serves constitutional goals |
| Resource Adequacy | Resources are sufficient |
| Schedule Feasibility | Schedule is achievable |
| Risk Acceptance | Risks are within acceptable range |
| Dependency Resolution | Dependencies are managed |
| Quality Standards | Deliverables meet quality requirements |

## Certificate Structure

Each certificate records: entity ID, certification type, per-check results, certifying entity, timestamp, fingerprint.
