# Technology Dependency Engine

## Purpose

Architect dependency graphs that capture how technologies depend on scientific theories, materials, manufacturing processes, infrastructure, and other technologies.

## Dependency Graph Structure

```
Scientific Theory
    ↓
Technology
    ↓
Subsystem
    ↓
Material
    ↓
Manufacturing
    ↓
Infrastructure
    ↓
Civilization
```

## Dependency Types

| Type | Description |
|------|-------------|
| Scientific Dependency | Depends on scientific knowledge |
| Technology Dependency | Depends on another technology |
| Material Dependency | Depends on specific materials |
| Manufacturing Dependency | Depends on manufacturing capability |
| Infrastructure Dependency | Depends on infrastructure |
| Resource Dependency | Depends on resource availability |

## Properties

- Every dependency is explicit
- Dependency strength is quantified
- Dependency chains are fully traceable
- Missing dependencies are flagged
- Dependency graphs are fully replayable
