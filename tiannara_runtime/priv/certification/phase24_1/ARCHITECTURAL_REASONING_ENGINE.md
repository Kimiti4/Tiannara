# Architectural Reasoning Engine

## Purpose

Architect constitutional reasoning over requirements, constraints, tradeoffs, scientific dependencies, technology dependencies, failure propagation, and future extensibility. Reasoning remains explainable.

## Reasoning Types

| Type | Description |
|------|-------------|
| Requirements Reasoning | How requirements drive architectural decisions |
| Constraint Reasoning | How constraints limit architectural options |
| Tradeoff Reasoning | How tradeoffs are identified and resolved |
| Dependency Reasoning | How scientific and technology dependencies shape architecture |
| Failure Propagation Reasoning | How failures propagate through the system |
| Extensibility Reasoning | How future evolution is accommodated |

## Reasoning Properties

- Every reasoning step is recorded
- Reasoning is fully deterministic
- Reasoning includes confidence and uncertainty
- Reasoning links to supporting evidence
- Alternative reasoning paths are preserved
