# Phase 17.5 — Constitutional Counterfactual World Modeling: Architecture

## 1. Purpose

Generate deterministic, replayable, mathematically verifiable alternative world histories from certified world models.

## 2. Principles

1. A counterfactual is not imagination — it is a deterministic branch from a certified world model.
2. Every intervention must be explicit and evidence-backed.
3. Every branch must be replayable from immutable artifacts.
4. No speculative branch without explicit assumptions.
5. No hidden interventions.
6. Mathematical verification is mandatory.
7. Archaeology is complete: every branch explains its origin.

## 4. Key Concepts

### Counterfactual World
An alternative world state generated by applying interventions to a certified parent world model.

### Intervention
A deterministic modification to the parent world model: variable fix, structural change, policy rule, engineering parameter, or environmental condition.

### Divergence Point
The exact state and time at which the counterfactual branch separates from the parent timeline.

### Branch Graph
A directed acyclic graph of counterfactual worlds: each branch has one parent (the world model it diverged from) and may have multiple children (further branches).

### Alternative Timeline
The sequence of world states from the divergence point forward under the counterfactual regime.

### Replay Root
A content-addressed hash of the full counterfactual specification for deterministic replay.

## 6. Ownership

Every counterfactual has a single owner (the generating process). Ownership is recorded in the archaeological record and is immutable.
