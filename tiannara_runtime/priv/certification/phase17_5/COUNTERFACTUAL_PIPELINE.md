# Phase 17.5 — Counterfactual Pipeline

## 1. Pipeline Stages

```
Stage 1: Intervention Specification
  Input:  Certified WorldModel + Intervention definition
  Output: Intervention record (variable, value, type, evidence)
  
Stage 2: Branch Generation
  Input:  WorldModel + Intervention record
  Output: BranchNode with divergence point
  
Stage 3: Timeline Construction
  Input:  BranchNode + WorldModel
  Output: AlternativeTimeline (sequence of world states)
  
Stage 4: Outcome Prediction
  Input:  AlternativeTimeline
  Output: Predicted outcomes (forecast under counterfactual regime)
  
Stage 5: Comparison
  Input:  Original timeline + Alternative timeline
  Output: BranchComparison (divergence, similarity, causal distance)
  
Stage 6: Validation
  Input:  Full counterfactual artifact
  Output: Validation result (causal, math, replay checks)
  
Stage 7: Archaeology
  Input:  Counterfactual artifact
  Output: CounterfactualEvidence (full lineage record)
  
Stage 8: Certification
  Input:  Validated counterfactual
  Output: Counterfactual certificate
```

## 2. Pipeline Execution Flow

```elixir
def run_counterfactual_pipeline(world_model, intervention, opts) do
  with {:ok, intervention_record} <- InterventionExecutor.execute(world_model, intervention),
       {:ok, branch} <- BranchGenerator.generate(world_model, intervention_record),
       {:ok, timeline} <- AlternativeTimeline.construct(world_model, branch),
       {:ok, outcomes} <- ForecastGenerator.generate(timeline.current_state, opts),
       {:ok, comparison} <- BranchComparator.compare(world_model, timeline),
       {:ok, validation} <- CounterfactualValidation.run(branch, timeline, comparison),
       {:ok, evidence} <- CounterfactualArchaeology.record(branch) do
    certify_counterfactual(branch, timeline, comparison, validation, evidence)
  end
end
```

```

  │                        │

  │                        │

  │                        │
  └── Evidence ───────────► CounterfactualEvidence
```

## 4. Determinism Guarantee

The pipeline is deterministic if:
- All inputs are content-addressed
- All random seeds are explicitly recorded
- The WorldModel is frozen (certified, not :draft)
- Interventions are fully specified (no ambiguity)
- Timelines are generated by deterministic simulation

## 5. Failure Modes

| Stage | Failure | Action |
|-------|---------|--------|
| Intervention | Invalid target variable | {:error, :invalid_target} |
| Intervention | Intervention conflicts with model constraints | {:error, :constraint_violation} |
| Branch | Divergence point out of range | {:error, :invalid_divergence} |
| Timeline | Simulation diverges (singularity) | {:error, :singularity} |
| Comparison | Incompatible state spaces | {:error, :incompatible_state_space} |
| Validation | Causal inconsistency | {:error, :causal_inconsistency} |
| Archaeology | Storage failure | {:error, :storage_failure} |
