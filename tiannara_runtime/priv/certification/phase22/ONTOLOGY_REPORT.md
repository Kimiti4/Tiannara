# Ontology Report

## Purpose

Generate comprehensive reports on the state, coverage, and quality of the Constitutional Civilizational Ontology.

## Report Sections

- Executive Summary
- Civilization Inventory
- Institution Landscape
- Infrastructure Map
- Knowledge Domain Coverage
- Resource System State
- Technology Capability Profile
- Societal Structure Overview
- Ontology Health
- Replay and Archaeology
- Extension Recommendations

## Frequency
- Standard: Per generation
- Comprehensive: Per 10 generations
