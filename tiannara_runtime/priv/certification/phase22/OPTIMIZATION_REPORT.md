# Optimization Report

## Purpose

Generate comprehensive reports on the state, results, and quality of civilization optimization.

## Report Sections

- Executive Summary
- Design Space Overview
- Candidate Generation Summary
- Constraint Satisfaction Report
- Objective Evaluation Results
- Pareto Frontier Analysis
- Tradeoff Documentation
- Recommended Designs
- Replay and Archaeology
- Optimization Recommendations

## Frequency
- Standard: Per generation
- Comprehensive: Per 10 generations
