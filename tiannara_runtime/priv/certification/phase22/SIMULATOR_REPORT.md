# Simulator Report

## Purpose

Generate comprehensive reports on simulation activities, discoveries, and civilization insights.

## Report Sections

- Executive Summary
- Simulation Overview
- Parameter Space Coverage
- Discovered Scenarios
- Statistical Findings
- Sensitivity Analysis Results
- Validation Assessment
- Key Insights for Civilization Design
- Replay and Archaeology
- Simulator Recommendations

## Frequency
- Standard: Per batch
- Comprehensive: Per 10 batches
