# Architect Metrics

## Purpose

Define quantitative metrics for measuring the quality, completeness, and utility of civilization architecture recommendations.

## Metrics

- **Requirement Coverage**: Fraction of requirements addressed
- **Architecture Completeness**: Coverage of civilizational dimensions
- **Constitutional Compliance Score**: Constitutional alignment verification (0.0–1.0)
- **Multi-Century Coherence**: Plan coherence across horizons
- **Alternative Diversity**: Number of architecture alternatives generated
- **Trade-off Resolution**: Clarity of trade-off documentation
- **Adaptive Capacity**: Architecture adaptability score
- **Replay Stability**: Target 99.9%
- **Archaeology Completeness**: Target 99%
- **Architecture Confidence**: Overall confidence in recommendations (0.0–1.0)
- **Civilization Architect Readiness**: Overall architect maturity index

## Target Thresholds

| Metric | Minimum | Target | Excellence |
|---|---|---|---|
| Requirement Coverage | 0.80 | 0.95 | 1.00 |
| Constitutional Compliance | 100% | 100% | 100% |
| Architecture Completeness | 0.70 | 0.90 | 0.99+ |
| Replay Stability | 99% | 99.9% | 99.99% |
| Archaeology Completeness | 95% | 99% | 100% |
