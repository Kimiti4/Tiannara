# Ecosystem Metrics

## Purpose

Define quantitative metrics for measuring multi-civilization ecosystem health, collaboration effectiveness, knowledge exchange, resource efficiency, diplomatic stability, and overall coordination system maturity.

## Metrics

| Metric | Description | Target |
|---|---|---|
| Collaboration Index | Fraction of possible collaborations realized | 0.75 |
| Knowledge Exchange Rate | Cross-civilization knowledge flow volume | ≥100 flows/year |
| Scientific Cooperation Score | Effectiveness of scientific collaborations (0.0–1.0) | 0.85 |
| Engineering Cooperation Score | Effectiveness of engineering collaborations (0.0–1.0) | 0.80 |
| Resource Efficiency | Resource utilization efficiency across ecosystem | 0.85 |
| Infrastructure Connectivity | Fraction of civilizations connected by shared infrastructure | 0.80 |
| Diplomatic Stability | Duration and consistency of diplomatic relationships | 0.85 |
| Ecosystem Resilience | Ability to maintain function under civilization-level disruptions | 0.80 |
| Replay Stability | Fraction of replays producing identical hashes | 99.9% |
| Archaeology Completeness | Fraction of ecosystem evolution reconstructible | 99% |
| Multi-Civilization Readiness Index | Overall coordination system maturity index | 0.85+ |

## Target Thresholds

| Metric | Minimum | Target | Excellence |
|---|---|---|---|
| Collaboration Index | 0.40 | 0.75 | 0.95 |
| Knowledge Exchange Rate | 10/yr | 100/yr | 1000/yr |
| Scientific Cooperation Score | 0.60 | 0.85 | 0.95 |
| Engineering Cooperation Score | 0.50 | 0.80 | 0.95 |
| Resource Efficiency | 0.60 | 0.85 | 0.95 |
| Infrastructure Connectivity | 0.40 | 0.80 | 1.00 |
| Diplomatic Stability | 0.60 | 0.85 | 0.95 |
| Ecosystem Resilience | 0.50 | 0.80 | 0.95 |
| Replay Stability | 99% | 99.9% | 99.99% |
| Archaeology Completeness | 95% | 99% | 100% |

## Measurement Methodology

- **Collaboration Index**: Ratio of active collaborations to potential collaborations
- **Knowledge Exchange Rate**: Count of documented knowledge transfers per year
- **Cooperation Scores**: Multi-factor quality assessments of collaboration outcomes
- **Resource Efficiency**: Output per unit resource across the ecosystem
- **Infrastructure Connectivity**: Fraction of civilization pairs with direct infrastructure links
- **Diplomatic Stability**: Mean duration of diplomatic agreements without renegotiation

## Constraints

- Metrics must be deterministically computable
- Metric records become constitutional artifacts
- Metrics preserve civilizational anonymity where appropriate
