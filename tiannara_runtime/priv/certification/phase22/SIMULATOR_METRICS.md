# Simulator Metrics

## Purpose

Define quantitative metrics for measuring simulation coverage, fidelity, and discovery effectiveness.

## Metrics

- **Simulation Coverage**: Fraction of parameter space explored
- **Simulation Fidelity**: Agreement with historical data
- **Scenario Discovery Rate**: Novel scenarios per batch
- **Statistical Significance**: Confidence in simulation findings
- **Parameter Sensitivity Coverage**: Parameters analyzed for sensitivity
- **Batch Efficiency**: Simulations completed per resource unit
- **Replay Stability**: Target 99.9%
- **Archaeology Completeness**: Target 99%
- **Simulation Confidence**: Overall confidence in simulation results (0.0–1.0)
- **Civilization Simulator Readiness**: Overall simulator maturity index

## Target Thresholds

| Metric | Minimum | Target | Excellence |
|---|---|---|---|
| Simulation Fidelity | 0.70 | 0.85 | 0.95+ |
| Parameter Coverage | 0.30 | 0.60 | 0.90+ |
| Replay Stability | 99% | 99.9% | 99.99% |
| Archaeology Completeness | 95% | 99% | 100% |
