# Scenario Discovery Engine

## Purpose

Automatically discover interesting, novel, or extreme scenarios from simulation results, identifying patterns that merit further investigation.

## Discovery Methods

### Automatic Clustering
- Simulation result clustering by outcome similarity
- Trajectory shape clustering
- Regime identification across simulations
- Hierarchical scenario taxonomy

### Novelty Detection
- Trajectories significantly different from typical
- Unexpected regime transitions
- Novel civilization configurations
- Unpredicted emergent behaviors

### Extreme Outcome Detection
- Best and worst case identification
- Collapse scenario discovery
- Breakthrough scenario detection
- Tipping point identification

### Pattern Recognition
- Repeating patterns across simulations
- Cycle and oscillation detection
- Phase transition identification
- Convergence and divergence patterns

## Scenario Classification

Each discovered scenario is classified:
- Scenario type (typical, novel, extreme, emergent)
- Probability of occurrence
- Key driving parameters
- Distinguishing characteristics

## Constraints

- Discovery must be deterministic
- Discovered scenarios become constitutional artifacts
- All scenarios are preserved for analysis
