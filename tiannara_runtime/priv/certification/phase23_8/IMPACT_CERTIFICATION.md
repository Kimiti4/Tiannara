# Impact Certification

## Purpose

Certify that impact predictions meet constitutional standards before being used for research prioritization or resource allocation.

## Certification Checks

| Check | Description |
|-------|-------------|
| Evidence Completeness | All supporting evidence is recorded |
| Causal Chain Completeness | Full causal chain from discovery to prediction |
| Uncertainty Preservation | All uncertainties are preserved and documented |
| Assumption Recording | All assumptions are explicitly recorded |
| Scenario Completeness | All relevant scenarios are considered |
| Risk Identification | All identified risks are documented |
| Explanation Quality | Prediction is self-explanatory |
| Constitutional Compliance | No constitutional violations |

## Certification Level

| Level | Meaning |
|-------|---------|
| Standard | All mandatory checks pass |
| Extended | Additional review of assumptions and scenarios |
| Peer Reviewed | Reviewed by other instances or participants |
| Constitutional | Highest level, full constitutional review |

## Certificate Structure

Each certificate records:
- Prediction ID or discovery ID
- Certification level
- Per-check results
- Certification timestamp
- Fingerprint (content hash)
