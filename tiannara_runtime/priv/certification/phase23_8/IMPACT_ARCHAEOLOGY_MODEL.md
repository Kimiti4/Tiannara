# Impact Archaeology Model

## Purpose

Reconstruct the complete history of impact predictions: why forecasts changed, which assumptions failed, which scenarios became reality, which opportunities were realized, which risks materialized, and the complete forecasting lineage.

## Reconstructable Questions

- Why did the impact forecast change between two dates?
- Which assumptions later proved incorrect?
- Which scenario branches became reality?
- Which predicted opportunities were realized?
- Which predicted risks materialized?
- What was the complete prediction lineage for a discovery?

## Archaeological Queries

| Query | Description |
|-------|-------------|
| ForecastEvolution(discovery_id) | How forecasts changed over time |
| AssumptionFailureAnalysis(time_range) | Which assumptions failed |
| ScenarioValidation(scenario_id) | Did the scenario match reality? |
| OpportunityRealization(opportunity_id) | Was the opportunity captured? |
| RiskMaterialization(risk_id) | Did the risk occur? |
| PredictionLineage(prediction_id) | Complete chain of predictions |

## Preservation

- All forecast events are permanently preserved
- No pruning or summarization of forecast history
- Archaeology operates on the same event log as replay
