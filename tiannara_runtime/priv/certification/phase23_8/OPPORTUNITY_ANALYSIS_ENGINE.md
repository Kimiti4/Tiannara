# Opportunity Analysis Engine

## Purpose

Identify scientific, engineering, industrial, educational, medical, planetary, civilizational, research, and innovation opportunities arising from a discovery.

## Opportunity Types

| Type | Description |
|------|-------------|
| Scientific | New research directions, unanswered questions, cross-domain breakthroughs |
| Engineering | New technologies, manufacturing methods, optimization, materials |
| Industrial | New industries, market creation, productivity gains |
| Educational | New fields of study, curriculum development, skill requirements |
| Medical | New treatments, diagnostics, preventive medicine |
| Planetary | Climate solutions, sustainability, resource efficiency |
| Civilizational | Long-term progress, resilience, complexity increase |
| Research | Future discoveries enabled, acceleration of knowledge |
| Innovation | Invention opportunities, combinatorial breakthroughs |

## Opportunity Properties

- Each opportunity has an estimated value (with uncertainty)
- Opportunities are linked to specific causal chains
- Opportunity dependencies are recorded
- Timeline estimates are recorded with uncertainty
