# Causal Propagation Engine

## Purpose

Propagate discovery effects through the constitutional causal graph. Represent direct effects, indirect effects, feedback loops, emergent effects, dependency cascades, and nonlinear amplification.

## Propagation Types

| Type | Description |
|------|-------------|
| Direct Effects | Immediate causal consequences of the discovery |
| Indirect Effects | Effects mediated through intermediate systems |
| Feedback Loops | Effects that amplify or dampen through cycles |
| Emergent Effects | System-level effects not predictable from components alone |
| Dependency Cascades | Effects that propagate through dependency networks |
| Nonlinear Amplification | Effects that grow disproportionately with scale |

## Propagation Properties

- Propagation is fully deterministic
- Causal chains are recorded for every predicted effect
- Each propagation step records confidence
- Propagation depth is configurable
- Pruning is explicit and recorded
