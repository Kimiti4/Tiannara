# Impact Priority Engine

## Purpose

Rank discoveries by their predicted impact to guide research allocation. Priority remains explainable.

## Priority Factors

| Factor | Description |
|--------|-------------|
| Scientific Benefit | Advancement of fundamental knowledge |
| Engineering Benefit | New capabilities and technologies |
| Planetary Benefit | Positive effects on planetary systems |
| Civilizational Benefit | Long-term benefit to civilization |
| Risk | Level of risk (negative priority) |
| Urgency | Time-sensitivity of the opportunity |
| Feasibility | Likelihood of successful integration |
| Long-Term Value | Value that grows over time |

## Priority Properties

- Priority is computed deterministically from impact assessments
- Each priority score records its component factors
- Alternative weighting schemes are maintained
- Priority is updated as new information arrives
- Priority disagreements between schemes are highlighted
- No single priority number is treated as definitive
