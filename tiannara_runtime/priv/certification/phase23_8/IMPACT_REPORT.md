# Impact Report

## Purpose

Generate comprehensive reports on impact predictions for observation, analysis, and strategic decision-making.

## Report Types

| Report | Content |
|--------|---------|
| Discovery Impact Summary | Impact forecast for a specific discovery |
| Risk Landscape | All current risk assessments |
| Opportunity Landscape | All current opportunity assessments |
| Scenario Overview | All active scenario trees |
| Priority Rankings | Ranked discoveries by impact |
| Forecast Accuracy | Comparison of predictions to outcomes |
| Uncertainty Audit | Analysis of uncertainty across predictions |
| Engineering Forecast | Engineering impact predictions |
| Planetary Forecast | Planetary impact predictions |
| Civilizational Forecast | Civilizational impact predictions |
| Long-Horizon Report | Long-term forecast summary |

## Report Properties

- All reports are deterministic
- Reports include machine-readable and human-readable formats
- Reports are time-stamped and archiveable
- Reports generated for any point in replay timeline
