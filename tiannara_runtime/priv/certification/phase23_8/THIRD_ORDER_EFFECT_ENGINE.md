# Third-Order Effect Engine

## Purpose

Predict third-order effects — consequences of the second-order effects. This captures long-range and subtle consequences that are often missed by shorter-horizon analysis.

## Examples

| Second-Order Effect | Potential Third-Order Effect |
|---------------------|------------------------------|
| Manufacturing adapted | Supply chain reconfigured |
| Healthcare infrastructure changes | Population health improves |
| Industry reorganization | New economic sectors emerge |
| Labor market shifts | Education systems adapt |
| Land use changes | Ecosystem patterns shift |

## Properties

- Third-order effects are derived from second-order effects
- Each third-order effect records its complete causal lineage
- Confidence decay is tracked at each order
- Higher-order effects (beyond third) can be computed on demand
