# Impact Identification Engine

## Purpose

Identify all systems affected by a scientific discovery. No domain is excluded from consideration.

## Affected Domains

| Domain | Examples |
|--------|----------|
| Science | All branches of natural, formal, and applied science |
| Engineering | All engineering disciplines |
| Medicine | Diagnostics, therapeutics, preventive medicine |
| Robotics | Autonomous systems, manipulation, navigation |
| Materials | New materials, metamaterials, nanomaterials |
| Energy | Generation, storage, transmission, efficiency |
| Governance | Policy, regulation, international relations |
| Agriculture | Crop yield, sustainability, food security |
| Computation | Hardware, software, algorithms, architectures |
| Economics | Productivity, markets, labor, wealth distribution |
| Ecology | Ecosystems, biodiversity, conservation |
| Planetary Systems | Climate, geology, oceans, atmosphere |
| Civilization | Social structures, culture, ethics, longevity |

## Identification Method

- Query the constitutional knowledge graph for systems that share causal relationships with the discovery domain
- Use the scientific taxonomy to identify cross-domain connections
- Apply constitutional causality rules to determine relevance
- Record confidence for each identification
