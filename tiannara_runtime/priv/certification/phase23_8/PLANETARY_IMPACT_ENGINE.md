# Planetary Impact Engine

## Purpose

Forecast effects of a discovery upon planetary systems: energy, climate, water, food, biodiversity, transportation, infrastructure, and resource consumption.

## Forecast Areas

| Area | Description |
|------|-------------|
| Energy | Changes in energy production, consumption, and efficiency |
| Climate | Effects on climate change mitigation and adaptation |
| Water | Changes in water availability, quality, and management |
| Food | Changes in food production, distribution, and security |
| Biodiversity | Effects on species, ecosystems, and conservation |
| Transportation | Changes in transportation systems |
| Infrastructure | Changes in built infrastructure |
| Resource Consumption | Changes in material and resource use |

## Planetary Impact Properties

- Impacts are quantified with uncertainty bounds
- Timescales are explicit
- Planetary boundary interactions are considered
- Feedback loops between planetary systems are recorded
- Irreversible changes are flagged
