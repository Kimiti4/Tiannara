# Adaptation Engine

## Purpose
Adjusts or halts interventions based on monitoring data — interventions must be adaptive because the planet is complex and predictions are uncertain.

## Adaptation Actions

### Continue
- Intervention is on track
- Continue as planned
- No changes needed

### Accelerate
- Intervention exceeding expectations
- Scale up or speed up deployment
- Advance next stage earlier

### Modify
- Partial course correction needed
- Adjust parameters, timing, or scope
- Keep main strategy intact

### Hold
- Pause at next hold point
- Await further information
- Re-evaluate before proceeding

### Abort
- Intervention failing or causing harm
- Initiate rollback procedure
- Notify all stakeholders

## Decision Framework

### Trigger-Based
- Predefined thresholds trigger adaptation actions
- Performance below threshold → modify or hold
- Harm above threshold → abort
- Performance above threshold → accelerate

### Review-Based
- Periodic scheduled reviews
- Major milestone reviews
- External event-triggered reviews

### Escalation
- If automatic adaptation is insufficient, escalate to human decision-makers
- Provide options with analysis
- Include recommendation

## Output
Adaptation decision: action type, rationale, supporting evidence, expected consequences of adaptation, implementation instructions.
