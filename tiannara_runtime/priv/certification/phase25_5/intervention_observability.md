# Intervention Observability

## Purpose
Observability for intervention systems — operators must be able to understand what CPISE is doing, why, and what the results are.

## Observability Data

### Strategy Observability
- Current active strategies
- Strategies under consideration
- Strategy generation history
- Constitutional check results

### Modeling Observability
- Current projections
- Uncertainty ranges
- Side effect profiles
- Scenario comparisons

### Optimization Observability
- Current resource allocation
- Pareto frontier
- Tradeoffs being made
- Allocation changes over time

### Deployment Observability
- Current deployment stage for each intervention
- Trigger condition status
- Rollout progress
- Deployment exceptions

### Monitoring Observability
- Effectiveness metrics
- Adaptation decisions
- Feedback loop status
- Performance trends

## Observability Interfaces
- Real-time dashboards
- Structured log streams
- Queryable history
- Alert channels

## Privacy
- Intervention details at appropriate classification
- Public summary always available
- Full detail to authorized operators only
- Audit log of who viewed what
