# Intervention Metrics

## Purpose
Health metrics for CPISE itself — monitoring the intervention engine's performance, accuracy, and reliability.

## Metrics

### Strategy Metrics
- Strategies generated per risk cycle
- Strategy quality score (how often recommended strategies succeed)
- Constitutional pass rate
- Cross-domain strategy fraction

### Modeling Metrics
- Prediction accuracy (projected vs. actual outcomes)
- Uncertainty calibration (confidence intervals covering true outcomes)
- Side effect prediction recall
- Model freshness (time since last calibration)

### Optimization Metrics
- Pareto frontier coverage
- Resource allocation efficiency
- Tradeoff clarity (are tradeoffs explicit?)
- Optimization runtime

### Deployment Metrics
- Deployment success rate
- Stage completion rate
- Rollback frequency
- Deployment delays

### Monitoring Metrics
- Detection latency (time from outcome to detection)
- Adaptation speed (time from detection to action)
- Feedback loop closure rate
- Monitoring coverage

### Integrity Metrics
- Replay accuracy
- Certification currency
- Archaeology completeness
- Observability availability

## Output
Metric dashboards, trend analysis, alert thresholds, health scores, and periodic reports.
