# Population State Model

## Purpose

Define the state representation for the population domain.

## State Variables

- **Total Population** — Global, regional, national, subnational.
- **Population Density** — People per square kilometer.
- **Age Distribution** — Population by age cohort.
- **Sex Distribution** — Population by sex.
- **Urban/Rural Split** — Urbanization rate.
- **Birth Rate** — Births per 1,000 population.
- **Death Rate** — Deaths per 1,000 population.
- **Fertility Rate** — Total fertility rate.
- **Life Expectancy** — At birth, by sex.
- **Migration** — Net migration rate.
- **Household Size** — Average household size.
- **Population Projections** — Future population estimates.

## Data Sources

- UN World Population Prospects.
- National census data.
- Vital statistics registries.
- Migration surveys.
- Satellite settlement data.

## Update Frequency

- Annual baseline updates.
- Quarterly projection updates.
- Event-driven updates for significant events.

## Uncertainty

- Census undercount estimates.
- Projection uncertainty bounds.
- Migration estimation uncertainty.
- Demographic model uncertainty.
