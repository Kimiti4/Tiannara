# State Observability

## Purpose

Define observability for the Planetary State Engine.

## Observable Dimensions

| Dimension | Description |
|---|---|
| Global Planetary Health | Aggregate planetary health index |
| Domain Health | Status and completeness per domain |
| Regional State | State by geographic region |
| State Evolution | State changes over time |
| Confidence Levels | Confidence scores across state |
| Missing Information | Data gaps and their severity |
| Observation Freshness | Age of observations feeding each domain |
| State Lineage | Provenance chain for state values |
| Uncertainty Density | Geographic distribution of uncertainty |
| Certification Status | Certification coverage per domain |

## Observatory Displays

- **Planetary Health Dashboard** — Global health index and trends.
- **Domain Status Board** — Status of all 20 domains.
- **State Evolution Viewer** — Temporal state visualization.
- **Confidence Map** — Geographic confidence visualization.
- **Gap Analysis** — Data gap visualization.
- **Lineage Explorer** — Provenance chain exploration.
- **Certification Status** — Certification coverage display.

## Alerting

- Domain completeness drops below threshold.
- Observation freshness exceeds maximum age.
- Cross-domain inconsistency detected.
- Uncertainty exceeds threshold.
- Certification expiration approaching.
- Data gap severity increases.
