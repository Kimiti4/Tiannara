# Infrastructure State Model

## Purpose

Define the state representation for the infrastructure domain.

## State Variables

- **Transportation** — Roads (km, paved %), railways (km), ports, airports.
- **Energy Infrastructure** — Power plants (type, capacity), grids (km), pipelines.
- **Water Infrastructure** — Dams, treatment plants, distribution networks.
- **Communication Infrastructure** — Fiber (km), cellular towers, internet exchange points.
- **Buildings** — Residential, commercial, industrial stock.
- **Urban Development** — Urban extent, density, land use.
- **Waste Management** — Collection coverage, treatment, recycling.
- **Healthcare Infrastructure** — Hospitals, clinics, beds.
- **Education Infrastructure** — Schools, universities, labs.
- **Research Infrastructure** — Laboratories, observatories, supercomputers.
- **Infrastructure Age** — Distribution of infrastructure age.
- **Infrastructure Condition** — Condition index by type.
- **Infrastructure Investment** — Public and private investment.

## Data Sources

- OpenStreetMap.
- National infrastructure databases.
- Satellite imagery.
- World Bank infrastructure data.
- Industry reports.

## Update Frequency

- Annual comprehensive surveys.
- Quarterly major project tracking.
- Real-time event-driven updates for damage.

## Uncertainty

- Infrastructure data completeness.
- Condition assessment subjectivity.
- Investment data reporting lags.
- Informal infrastructure estimation.
