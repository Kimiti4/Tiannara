# State Report

## Purpose

Provide comprehensive reporting on planetary state status and health.

## Report Sections

### Executive Summary
- Planetary state overall health.
- Domain completeness scores.
- Key state changes since last report.
- Critical data gaps.
- Recommendations.

### Domain Status
- Status of each domain.
- Domain completeness percentage.
- Observation freshness.
- Uncertainty levels.
- Cross-domain consistency.

### State Health Metrics
- State Completeness Index.
- Observation Freshness Index.
- Confidence Index.
- Uncertainty Density.
- Certification Coverage.
- Replay Accuracy.

### Data Gap Analysis
- Missing domains or variables.
- Geographic coverage gaps.
- Temporal coverage gaps.
- Quality gaps (low confidence areas).

### Uncertainty Report
- Major uncertainty sources.
- Uncertainty trends by domain.
- Uncertainty reduction recommendations.

### Certification Status
- Domain certification status.
- Pending certifications.
- Expired certifications.
- Compliance rate.

### Recommendations
- Data source additions.
- Domain model improvements.
- Uncertainty reduction priorities.
- Certification priorities.
