# Biodiversity State Model

## Purpose

Define the state representation for the biodiversity domain.

## State Variables

- **Species Richness** — Number of species by taxonomic group.
- **Population Abundance** — Living Planet Index (LPI).
- **Extinction Risk** — IUCN Red List categories.
- **Habitat Extent** — Forest, wetland, coral reef, grassland area.
- **Habitat Fragmentation** — Connectivity indices.
- **Protected Areas** — Coverage by IUCN category.
- **Invasive Species** — Number and impact.
- **Genetic Diversity** — Genetic diversity indices.
- **Ecosystem Services** — Pollination, water purification, carbon storage.
- **Marine Biodiversity** — Fish stocks, coral health.
- **Freshwater Biodiversity** — River and lake biodiversity.
- **Forest Cover** — Canopy cover, deforestation rate.
- **Wildlife Population Trends** — Key species populations.

## Data Sources

- IUCN Red List.
- Living Planet Index (WWF/ZSL).
- Global Forest Watch.
- GBIF occurrence data.
- Satellite remote sensing.
- Citizen science (eBird, iNaturalist).
- FAO fisheries data.

## Update Frequency

- Annual species assessments.
- Quarterly ecosystem area updates.
- Real-time alerts for critical events.

## Uncertainty

- Species population estimation uncertainty.
- Habitat mapping resolution limits.
- Citizen science data bias.
- Extinction risk assessment subjectivity.
