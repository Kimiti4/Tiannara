# Theory Ecology Engine

## Purpose

Treat theories as evolving populations. Manage the full lifecycle of theories
from birth through competition, coexistence, merge, split, replacement, and
retirement. No theory is ever erased.

## Lifecycle Stages

```
Birth → Growth → Competition → Coexistence → Merge/Split →
Replacement → Retirement
```

## Stage Descriptions

| Stage | Description |
|-------|-------------|
| Birth | New theory formed from models, laws, and discoveries |
| Growth | Theory gains supporting evidence and refinements |
| Competition | Multiple theories compete for the same explanatory domain |
| Coexistence | Incompatible theories coexist with documented contradictions |
| Merge | Compatible theories unify into a more comprehensive theory |
| Split | A theory decomposes into focused sub-theories |
| Replacement | A newer theory subsumes an older one |
| Retirement | Theory is superseded but not deleted; archaeologically preserved |

## Population Metrics

- Theory count per domain
- Theory diversity (distribution across domains/paradigms)
- Theory stability (how often a theory changes)
- Theory lifespan (time from birth to retirement)
- Competition density (number of competing theories per question)

## Constitutional Rules

- Retired theories remain fully accessible
- No theory can be permanently deleted
- All lifecycles are fully replayable
