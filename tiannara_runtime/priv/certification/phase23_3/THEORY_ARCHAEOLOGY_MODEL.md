# Theory Archaeology Model

## Purpose

Reconstruct the complete scientific evolution of the system: why theories
formed, why they merged or split, why paradigms changed, and how unified
frameworks emerged. Archaeology provides the full narrative of scientific
understanding evolution.

## Reconstructable Questions

- Why did this theory form when it did?
- What discoveries drove theory formation?
- Why did two theories merge?
- What contradictions led to a split?
- How did the dominant paradigm change?
- Which discoveries reshaped scientific understanding?
- What unified frameworks emerged and why?
- What alternative theories were considered?

## Archaeological Queries

| Query | Description |
|-------|-------------|
| TheoryLineage(id) | Full ancestry of a theory, including alternatives |
| ContradictionHistory(id) | All contradictions involving this entity |
| ParadigmTimeline(domain) | Paradigm evolution in a domain |
| CrossDomainInfluence(from, to) | How theories in one domain affected another |
| EvidenceImpact(discovery_id) | Which theories changed due to this discovery |
| FrameworkEvolution(framework_id) | How a unified framework developed |

## Preservation

- All theory events are permanently preserved
- No pruning or summarization of event history
- Archaeology operates on the same event log as replay
