# Theory Splitting Engine

## Purpose

Decompose theories that have become internally inconsistent, over-generalized,
domain-fragmented, or prediction-divergent into focused sub-theories.

## When to Split

| Condition | Description |
|-----------|-------------|
| Internal Inconsistency | Theory makes contradictory predictions in different sub-domains |
| Over-Generalization | Theory covers too many domains with degrading accuracy |
| Domain Fragmentation | Theory has become a collection of loosely connected sub-theories |
| Prediction Divergence | Predictions for different sub-domains have diverged beyond uncertainty |

## Splitting Process

1. Identify the dimension along which the theory has fragmented
2. Partition evidence, laws, and models along that dimension
3. Construct sub-theories for each partition
4. Assign each sub-theory its scope, assumptions, and evidence
5. Record lineage (original theory as parent)
6. Flag original theory as superseded (not deleted)
7. Submit sub-theories to Theory Evaluation Engine

## Constitutional Rules

- Every split produces exactly reconstructible lineage
- No evidence is discarded during a split
- Each sub-theory inherits the constitutional constraints of the parent
- Splits are reversible (the parent can be reconstructed)
