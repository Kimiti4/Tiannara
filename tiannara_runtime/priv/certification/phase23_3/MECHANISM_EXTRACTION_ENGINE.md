# Mechanism Extraction Engine

## Purpose

Extract reusable scientific mechanisms from discovery clusters. Mechanisms
become first-class scientific objects that can be composed, compared, and
referenced by laws and models.

## Mechanism Types

| Type | Description |
|------|-------------|
| Causal | A causes B under specified conditions |
| Physical | Force, field, thermodynamic, quantum mechanisms |
| Chemical | Reaction, bonding, catalytic mechanisms |
| Biological | Evolutionary, ecological, physiological mechanisms |
| Engineering | Control, feedback, optimization mechanisms |
| Computational | Algorithmic, information-theoretic mechanisms |
| Social | Coordination, game-theoretic, network mechanisms |
| Economic | Market, incentive, resource allocation mechanisms |

## Mechanism Structure

Each mechanism records:
- Mechanism type
- Participating variables
- Functional relationship description
- Boundary conditions
- Supporting evidence IDs
- Supporting discovery IDs
- Known counterexamples
- Uncertainty estimate
- Lineage (derived from which clusters/discoveries)

## Reusability

Mechanisms are indexed and cross-referenced. The same mechanism may
appear in multiple laws, models, and theories across domains.
