# Theory Contradiction Engine

## Purpose

Represent, store, and track contradictions between theories, laws, models,
and evidence. Contradictions are permanent scientific evidence that cannot
be hidden or erased.

## Contradiction Types

| Type | Description |
|------|-------------|
| Logical | Theories make logically incompatible statements |
| Empirical | Theories disagree with observed data |
| Causal | Theories posit contradictory causal mechanisms |
| Prediction | Theories predict different outcomes for the same scenario |
| Engineering | Theories imply incompatible engineering approaches |

## Contradiction Structure

Each contradiction records:
- Contradiction type
- Conflicting entity IDs (theories, laws, models, evidence)
- Nature of conflict (specific propositions that conflict)
- Supporting evidence for each side
- Resolution history (if any)
- Uncertainty weights for each side
- Timestamp of discovery
- Fingerprint (content hash)

## Constitutional Rules

- Contradictions cannot be deleted
- Contradictions cannot be suppressed
- Any resolution must reference the contradiction
- Resolved contradictions remain visible in archaeology
