# Explanation Engine

## Purpose

Ensure every theory, law, model, and framework remains explainable. Generate
human-readable and machine-readable explanations of scientific knowledge.

## Required Explanations

Every theory must explain:
- **What it predicts**: testable implications
- **Why it predicts it**: causal/mathematical/logical derivation
- **Which evidence supports it**: specific discovery IDs
- **Which assumptions exist**: explicit and implicit assumptions
- **What contradicts it**: documented contradictions
- **How confidence changes**: what would change the confidence
- **What engineering utility exists**: what the theory enables

## Explanation Structure

Each explanation records:
- Target entity ID (theory, law, model, framework)
- Explanation text (structured, deterministic)
- Evidence chain (discoveries → laws → models → theory)
- Assumption chain (what depends on what)
- Contradiction map (conflicting entities and nature of conflict)
- Confidence statement (why this certainty level)
- Provenance (which engine generated this explanation)

## Constitutional Rules

- All explanations must be deterministic
- No opaque theories permitted
- Explanations must be regenerable from stored data
