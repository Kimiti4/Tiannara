# Theory Report

## Purpose

Generate comprehensive reports on the state of scientific knowledge for
observation, analysis, and decision-making.

## Report Types

| Report | Content |
|--------|---------|
| Theory Ecology Summary | All active theories, their scores, and relationships |
| Theory Competition Report | Overlapping theories and their contradictions |
| Paradigm Status Report | Current paradigm landscape and transitions |
| Unified Framework Summary | All frameworks and their domain coverage |
| Scientific Law Catalog | All laws organized by domain and type |
| Contradiction Map | All open contradictions and their status |
| Evolution Timeline | History of theory changes in a domain |
| Engineering Transfer Report | Theories selected for engineering transfer |
| Cross-Domain Connections | Shared principles across domains |
| Uncertainty Assessment | Overall confidence across the knowledge base |

## Report Properties

- All reports are deterministic (same state → same report)
- Reports include machine-readable and human-readable formats
- Reports are time-stamped and archiveable
- Reports can be generated for any point in the replay timeline
