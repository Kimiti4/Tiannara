# Paradigm Detection Engine

## Purpose

Identify dominant, emerging, declining, and fragmented paradigms within the
theory ecology. Detect revolutionary shifts and paradigm transitions.

## Paradigm Types

| Type | Description |
|------|-------------|
| Dominant | Most theories in a domain share core assumptions |
| Emerging | New theories gaining evidence and adoption |
| Declining | Established theories losing explanatory power |
| Fragmented | No consensus; many competing theories |
| Revolutionary | A paradigm shift is occurring |

## Detection Signals

- Concentration of theory mass (how many theories share core assumptions)
- Rate of new theory formation within a paradigm
- Rate of contradiction discovery between paradigms
- Evidence accumulation rate for competing paradigms
- Engineering utility shifts (which paradigm enables more)
- Citation and reference patterns

## Paradigm Transition

When a paradigm shift is detected:
1. Document the transition candidates
2. Record the evidence driving the shift
3. Track the timeline of the transition
4. Preserve the old paradigm's theories (never deleted)
5. Flag for observatory visualization
