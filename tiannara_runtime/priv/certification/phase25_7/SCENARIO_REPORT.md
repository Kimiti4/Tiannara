# Scenario Report

## Purpose
Generates comprehensive reports on future scenarios for human decision-makers.

## Report Types

### Future Landscape Report
- Current scenario set overview
- Scenario probability distribution
- Key divergences and convergences
- Critical uncertainties

### Horizon Report
- Snapshot of civilization at a specific future time
- Across all scenarios (probability-weighted)
- Best-case, expected-case, worst-case
- Key risks and opportunities

### Comparison Report
- Side-by-side comparison of selected scenarios
- Differences highlighted
- Common features identified

### Evidence Impact Report
- How recent evidence changed probabilities
- Most influential evidence items
- Uncertainty reduction achieved

### Black Swan Report
- Current black swan catalog
- Probability ranges
- Impact assessments
- Precursor monitoring status

### Decision Support Report
- How scenarios inform specific decisions
- Which decisions are robust across scenarios
- Which decisions depend on scenario resolution

## Report Format
Structured (JSON) with human-readable summaries (Markdown), designed for the Constitutional Observatory.
