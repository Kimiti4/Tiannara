# Resource Evolution Engine

## Purpose
Models the long-term evolution of planetary and space resources — depletion, discovery, substitution, and space resource development.

## Resource Evolution Dimensions

### Depletion
- Non-renewable resource depletion timelines
- Peak production curves for critical minerals
- Aquifer depletion and soil degradation
- Biodiversity loss

### Discovery
- New reserve discoveries (geological exploration)
- New resource classes (deep sea, atmospheric, space)
- Technological creation (synthetic alternatives)

### Substitution
- Scarce resource substitution pathways
- Technology-driven demand reduction
- Material efficiency improvements
- Recycling and circular economy evolution

### Space Resources
- Near-Earth asteroid resource assessment
- Lunar resource extraction timeline
- Martian resource utilization
- Asteroid belt development
- Solar system resource economy

### Resource Scarcity Interactions
- Energy-water-food nexus evolution
- Critical mineral competition
- Resource-driven conflict scenarios
- Resource abundance scenarios (fusion, asteroid mining)

## Integration
- Resource evolution feeds scenario probability evolution
- Resource availability constrains technology and infrastructure evolution
- Resource conflicts appear as branching points

## Output
Resource depletion timelines, discovery projections, substitution pathways, space resource development timeline, resource abundance scenarios.
