# Scenario Generation Engine

## Purpose
Generates the initial set of plausible future scenarios from the current planetary state and evidence.

## Generation Approach

### Baseline Scenario
- Continue current trends with no major disruptions
- Extrapolate known trajectories (population, technology, economy, climate)
- Provides reference point for all other scenarios

### Variation Dimensions
- **Technology** — rate and direction of technological progress
- **Climate** — emission pathways, warming scenarios, tipping points
- **Governance** — cooperation vs. conflict, institutional evolution
- **Economy** — growth, stagnation, collapse, transformation
- **Population** — growth, decline, distribution shifts
- **Energy** — transition pace, source mix, availability
- **Science** — discovery rate, paradigm shifts, limits
- **Space** — expansion pace, resource access, colonization

### Scenario Generation Methods
- **Extrapolative** — extend current trends with variations
- **Normative** — start from desired end-state, work backward
- **Exploratory** — explore possibility space systematically
- **Counterfactual** — what if key events happened differently
- **Black swan** — incorporate low-probability, high-impact events

### Constraints
- Scenarios must be physically possible
- Scenarios must be evidence-consistent (not contradicted by known data)
- Scenarios must be constitutionally permissible (no rights violations)
- Minimum probability threshold (extremely low probability scenarios tracked separately)

## Output
Initial scenario set: baseline + N variations across key dimensions, each with initial assumptions, evidence basis, and placeholder probability.
