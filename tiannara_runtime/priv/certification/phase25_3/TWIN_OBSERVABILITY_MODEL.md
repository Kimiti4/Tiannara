# Twin Observability Model

## Purpose

Define observability for the planetary digital twin.

## Observable Dimensions

| Dimension | Description |
|---|---|
| Planetary Twin | Overall twin status and health |
| Scenario Comparison | Side-by-side scenario visualization |
| Twin Synchronization | Sync status with state engine |
| Layer Health | Each layer's status and fidelity |
| Infrastructure Evolution | Infrastructure changes over time |
| Scientific Capacity | Scientific capability trends |
| Engineering Capacity | Engineering capability trends |
| Civilizational Trends | Long-term civilization metrics |
| Twin Confidence | Confidence levels across twin |
| Replay Status | Replay system health |

## Observatory Displays

- **Twin Dashboard** — Overall twin health and fidelity.
- **Layer Status Board** — Layer fidelity and uncertainty.
- **Scenario Comparison** — Side-by-side scenario outcomes.
- **Synchronization Status** — Twin sync with state engine.
- **Fidelity Map** — Geographic fidelity visualization.
- **Uncertainty Map** — Geographic uncertainty visualization.
- **Scenario Timeline** — Scenario evolution visualization.
- **Model Version History** — Model changes over time.

## Alerting

| Level | Condition |
|---|---|
| Warning | Twin fidelity drops below threshold |
| Critical | Twin synchronization lost |
| Warning | Layer uncertainty exceeds threshold |
| Info | New scenario diverging significantly |
| Critical | Twin state diverging from observed state |
| Warning | Cross-layer inconsistency detected |
