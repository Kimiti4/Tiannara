# Generation Promotion (Phase 20.9)

## Purpose

Generation Promotion manages the cross-generation lifecycle — the promotion of an entire generation from candidate status to current production status. It wraps the six-engine integration pipeline into a cohesive generation lifecycle.

## Generation Lifecycle

```
Blueprint
    → CandidateGeneration
        → ValidatedGeneration
            → IntegrationReady
                → SandboxDeployment
                    → CanaryDeployment
                        → ProductionCandidate
                            → CurrentGeneration
                                → HistoricalGeneration
```

## Promotion Gates

Each gate requires:
1. **Decision Gate** — IntegrationProposal approved by Decision Engine
2. **Compatibility Gate** — Compatibility report clear
3. **Promotion Gate** — PromotionDecision for stage transition
4. **Transition Gate** — GenerationTransition executed
5. **Rollforward Gate** — RollforwardRecord verified
6. **Certification Gate** — SelfIntegrationCertificate issued

## Cross-Generation Properties

- **Immutability** — Previous generations are frozen once superseded
- **Replayability** — Full replay chain maintained across generations
- **Archaeology** — All generations preserved in cold storage
- **Rollback** — Any generation can be restored from archaeology
- **Lineage** — Complete parent/child generation tree maintained

## Output

Complete generation promotion package including:
- All engine outputs (decisions, compatibility, promotion, transition, rollforward)
- Certification artifacts
- Replay chain
- Archaeology deposit records
- Promotion summary report
