# Rollforward Engine (Phase 20.9)

## Purpose

The Rollforward Engine executes the forward migration from source generation to target generation. It applies deterministic transformations across all seven constitutional domains, verifies each transformation, and produces a complete RollforwardRecord.

## Transformation Pipeline

For each domain, the engine:
1. Reads source state (via snapshot hash)
2. Applies deterministic transformation function
3. Verifies output against expected hash
4. Records transformation step
5. Chains step hashes into domain transformation chain

## Seven Domain Transformations

1. **State Transformation** — Migrate state structures, preserve data
2. **Knowledge Migration** — Apply knowledge schema changes, preserve axioms
3. **Mathematical Migration** — Update mathematical foundations, preserve theorems
4. **World Model Migration** — Evolve world model, preserve environmental constraints
5. **Planning Migration** — Update planning algorithms, preserve goal structures
6. **Runtime Migration** — Apply runtime changes, preserve behavior
7. **Archaeology Migration** — Update archaeology schema, preserve records

## Verification

Each domain transformation is verified by:
- Input hash matches expected source hash
- Output hash matches expected target hash
- Transformation steps are deterministic
- Step hashes chain correctly
- Complete rollforward hash is computed

## Output

RollforwardRecord containing:
- Source and target generation IDs
- Per-domain transformation records (input_hash, output_hash, steps)
- Combined rollforward hash
- Verification results
- Status (Planned/Executing/Completed/RolledBack)
- Fingerprint

## Constraints

- All transformations are deterministic
- Full replay from any intermediate state
- Reversible via rollback plan
- No data loss during migration
- Transformation audit trail preserved
