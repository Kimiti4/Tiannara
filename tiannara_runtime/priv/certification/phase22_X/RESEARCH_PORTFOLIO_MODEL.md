# Research Portfolio Model

## Purpose

Manage the full lifecycle of research portfolios — collections of programs organized around scientific vision — supporting creation, expansion, merge, split, suspension, retirement, and rebalancing.

## Portfolio Structure

Each portfolio contains:

- **Portfolio ID**: Content-addressed identifier
- **Vision**: Scientific vision guiding the portfolio
- **Programs**: Research programs within portfolio
- **Dependencies**: Cross-program dependency graph
- **Resources**: Total resource allocation
- **Risk Profile**: Portfolio-level risk assessment
- **Performance**: Aggregate portfolio performance metrics
- **Rebalancing History**: Complete record of portfolio changes

## Portfolio Operations

### Program Creation
- New program proposal evaluation
- Resource allocation for new program
- Portfolio integration planning
- Dependency analysis with existing programs

### Program Expansion
- Scope expansion governance
- Additional resource allocation
- Milestone and timeline revision
- Stakeholder coordination

### Program Merge
- Merge justification and evidence
- Combined program design
- Resource consolidation planning
- Lineage preservation from both source programs

### Program Split
- Split justification and evidence
- New program boundary definition
- Resource division protocol
- Lineage preservation for both resulting programs

### Program Suspension
- Suspension criteria evaluation
- Resource reallocation plan
- Suspension duration governance
- Reactivation conditions

### Program Retirement
- Retirement criteria evaluation
- Knowledge archival protocol
- Resource release
- Legacy documentation

### Portfolio Rebalancing
- Periodic portfolio health assessment
- Resource reallocation across programs
- Priority-based rebalancing
- Rebalancing documentation with lineage

## Constraints

- Portfolio evolution preserves complete lineage
- Portfolio records become constitutional artifacts
- Portfolio decisions are evidence-driven
