# Imagination Archaeology Model

## Purpose

Define the archaeology model for the scientific imagination system — enabling reconstruction of why each hypothesis was generated, which knowledge gap motivated it, which assumptions were modified, which validation path was proposed, whether it succeeded, and how it influenced future discoveries.

## Archaeological Questions

### Hypothesis Origins
- Why was this hypothesis generated?
- Which knowledge gap motivated it?
- What evidence or anomaly prompted it?
- What prior hypotheses influenced it?

### Assumption Analysis
- Which assumptions were modified?
- Why were those assumptions chosen?
- What alternative assumptions were considered?
- What was the rationale for the modification?

### Validation Path
- Which validation path was proposed?
- What experiments were required?
- What simulations were needed?
- What mathematical proofs were required?

### Outcome Assessment
- Did the hypothesis eventually succeed?
- Was it validated, modified, or discarded?
- What evidence supported or contradicted it?
- What lessons were learned?

### Influence Tracking
- How did the hypothesis influence future discoveries?
- What subsequent hypotheses built on it?
- What experiments were inspired by it?
- What engineering innovations resulted?

## Archaeology Structure

Each archaeology record contains:

- **Imagination Period**: Time period analyzed
- **Hypothesis Histories**: Evolution of generated hypotheses
- **Counterfactual Records**: Counterfactual worlds generated
- **Innovation Records**: Engineering concepts generated
- **Validation Outcomes**: Which ideas succeeded or failed
- **Influence Assessment**: Impact on scientific progress
- **Key Discoveries**: Major outcomes from imagination
- **Fingerprint**: Deterministic content hash

## Archaeology Completeness

Archaeology is complete when all archaeological questions are answered with deterministic references to original constitutional artifacts.
