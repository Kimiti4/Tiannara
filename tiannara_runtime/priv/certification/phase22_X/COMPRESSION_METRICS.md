# Compression Metrics

## Purpose

Define quantitative metrics for measuring knowledge compression effectiveness, principle discovery rate, law discovery rate, cross-domain generalization, knowledge redundancy, and overall compression system readiness.

## Metrics

| Metric | Description | Target |
|---|---|---|
| Compression Ratio | Size reduction from raw observations to principles | ≥100:1 |
| Information Preservation | Fraction of significant information preserved | ≥0.99 |
| Principle Discovery Rate | New principles extracted per period | ≥10/period |
| Law Discovery Rate | New scientific laws formulated per period | ≥2/period |
| Cross-Domain Generalization | Fraction of abstractions linking ≥2 domains | 0.50 |
| Knowledge Redundancy | Fraction of knowledge base identified as redundant | <0.10 |
| Replay Stability | Fraction of replays producing identical hashes | 99.9% |
| Archaeology Completeness | Fraction of compression history reconstructible | 99% |
| Knowledge Compression Readiness | Overall compression system maturity index | 0.85+ |

## Target Thresholds

| Metric | Minimum | Target | Excellence |
|---|---|---|---|
| Compression Ratio | 10:1 | 100:1 | 1000:1 |
| Information Preservation | 0.95 | 0.99 | 0.999 |
| Principle Discovery Rate | 2/period | 10/period | 50/period |
| Law Discovery Rate | 0.5/period | 2/period | 10/period |
| Cross-Domain Generalization | 0.20 | 0.50 | 0.80 |
| Knowledge Redundancy | <0.20 | <0.10 | <0.05 |
| Replay Stability | 99% | 99.9% | 99.99% |
| Archaeology Completeness | 95% | 99% | 100% |

## Measurement Methodology

- Compression Ratio: Raw observation bytes / principle representation bytes
- Information Preservation: Fraction of information-theoretic content preserved
- Principle Discovery Rate: Newly certified principles per assessment period
- Law Discovery Rate: Newly certified scientific laws per assessment period
- Cross-Domain Generalization: Abstractions spanning ≥2 domains / total abstractions
- Knowledge Redundancy: Redundant knowledge artifacts / total knowledge artifacts

## Constraints

- Metrics must be deterministically computable
- Metric records become constitutional artifacts
