# Discovery Economics Archaeology Model

## Purpose

Define the archaeology model for discovery economics — enabling reconstruction of why resources were allocated, which discoveries justified investment, which programs produced the highest return, how allocation evolved, and what resources became bottlenecks.

## Archaeological Questions

### Allocation Rationale
- Why were resources allocated to specific programs?
- What priority evidence drove allocation?
- What expected return justified investment?
- What constitutional constraints shaped allocation?

### Investment Justification
- Which discoveries justified the investment?
- What expected outcomes were projected?
- What risk assessment was performed?
- What alternatives were considered?

### Return Assessment
- Which programs produced the highest return?
- Which programs underperformed expectations?
- What was the actual vs expected return?
- What factors drove return variance?

### Allocation Evolution
- How did allocation evolve?
- What triggered reallocation?
- How did priorities shift?
- What resource conflicts arose?

### Bottleneck History
- What resources became bottlenecks?
- When did bottlenecks emerge?
- How were bottlenecks resolved?
- What bottlenecks persist?

## Archaeology Structure

Each archaeology record contains:

- **Resource Period**: Time period analyzed
- **Allocation Rationale**: Why resources were allocated
- **Investment Record**: Which discoveries justified investments
- **Return History**: Actual vs expected returns
- **Evolution History**: How allocation evolved
- **Bottleneck History**: Resource bottlenecks
- **Key Decisions**: Major resource decisions
- **Fingerprint**: Deterministic content hash

## Archaeology Completeness

Archaeology is complete when all archaeological questions are answered with deterministic references to original constitutional artifacts.
