# Hypothesis Generation Model

## Purpose

Generate scientifically testable hypotheses from knowledge gaps — proposing plausible explanatory models, testable predictions, and experimental approaches while maintaining clear separation from validated knowledge.

## Hypothesis Sources

### Knowledge Gap-Driven
- Unexplained phenomena
- Anomalous observations
- Theoretical inconsistencies
- Predictive failures
- Cross-domain contradictions

### Theory-Driven
- Theory extension possibilities
- Theory unification opportunities
- Theory boundary exploration
- Theory conflict resolution

### Observation-Driven
- New observational data
- Unexpected measurement results
- Pattern discovery
- Correlation identification

### Counterfactual-Driven
- Insights from counterfactual worlds
- Alternative assumption implications
- Modified law predictions
- Novel paradigm suggestions

## Hypothesis Components

Each hypothesis contains:

- **Hypothesis ID**: Content-addressed identifier
- **Question**: The scientific question addressed
- **Assumptions**: Underlying assumptions
- **Predictions**: Testable predictions
- **Supporting Knowledge**: Existing knowledge supporting the hypothesis
- **Expected Evidence**: What evidence would confirm or falsify
- **Scientific Domains**: Relevant domains
- **Novelty Assessment**: How novel the hypothesis is
- **Plausibility**: Initial plausibility assessment
- **Classification**: Speculative confidence classification
- **Fingerprint**: Deterministic content hash

## Generation Process

1. **Gap Analysis**: Identify promising knowledge gaps
2. **Question Formulation**: Formulate precise scientific question
3. **Assumption Articulation**: State assumptions explicitly
4. **Prediction Derivation**: Derive testable predictions
5. **Evidence Assessment**: Assess existing evidence
6. **Experimental Design**: Suggest experimental approaches
7. **Classification**: Classify speculative confidence
8. **Recording**: Document with lineage

## Constraints

- Hypotheses are constitutionally separated from validated knowledge
- Hypothesis records become constitutional artifacts
- All hypotheses are replayable
