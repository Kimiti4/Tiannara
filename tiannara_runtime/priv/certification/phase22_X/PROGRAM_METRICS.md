# Program Metrics

## Purpose

Define quantitative metrics for measuring research portfolio health, scientific yield, engineering yield, knowledge growth, cross-domain integration, program survival, and overall scientific governance readiness.

## Metrics

| Metric | Description | Target |
|---|---|---|
| Portfolio Diversity | Distribution of programs across domains | 0.70 |
| Scientific Yield | Significant discoveries per program per year | ≥2 |
| Engineering Yield | Engineering insights per program per year | ≥3 |
| Knowledge Growth | New knowledge volume per period | ≥10% |
| Cross-Domain Integration | Fraction of programs with interdisciplinary links | 0.80 |
| Program Survival | Fraction of programs reaching planned completion | 0.75 |
| Replay Stability | Fraction of replays producing identical hashes | 99.9% |
| Archaeology Completeness | Fraction of program history reconstructible | 99% |
| Scientific Governance Readiness | Overall governance system maturity index | 0.85+ |

## Target Thresholds

| Metric | Minimum | Target | Excellence |
|---|---|---|---|
| Portfolio Diversity | 0.40 | 0.70 | 0.90 |
| Scientific Yield | 0.5/yr | 2/yr | 5/yr |
| Engineering Yield | 1/yr | 3/yr | 10/yr |
| Knowledge Growth | 5% | 10% | 20% |
| Cross-Domain Integration | 0.50 | 0.80 | 0.95 |
| Program Survival | 0.60 | 0.75 | 0.90 |
| Replay Stability | 99% | 99.9% | 99.99% |
| Archaeology Completeness | 95% | 99% | 100% |

## Measurement Methodology

- Portfolio Diversity: Herfindahl-Hirschman Index across domains
- Scientific Yield: Count of verified significant discoveries
- Engineering Yield: Count of engineering-relevant insights
- Knowledge Growth: Knowledge base size increase rate
- Cross-Domain Integration: Programs with ≥2 domain connections
- Program Survival: Ratio of completed to total programs

## Constraints

- Metrics must be deterministically computable
- Metric records become constitutional artifacts
