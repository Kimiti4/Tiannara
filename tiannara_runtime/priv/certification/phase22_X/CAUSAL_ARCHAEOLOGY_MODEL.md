# Causal Archaeology Model

## Purpose

Define the archaeological framework for reconstructing the evolution of the unified causal graph — understanding why causal relationships were introduced, which evidence supported them, which mathematical principles constrained them, and how the causal graph evolved over time.

## Archaeological Questions

### Causal Relationship Origins
- Why was this causal relationship introduced?
- Which evidence supported its introduction?
- What alternative causal explanations were considered?
- Which mathematical principles constrained the relationship?

### Evidence Evolution
- How did evidence for causal relationships change over time?
- Which relationships were strengthened or weakened by new evidence?
- Which relationships were refuted and removed?
- How did confidence in causal relationships evolve?

### Emergence History
- Which higher-level systems emerged from lower-level configurations?
- When did emergence boundaries shift?
- Which emergent properties were discovered or refined?
- How did emergence understanding deepen?

### Constraint Evolution
- Which higher-level constraints were introduced or removed?
- How did constraints propagate through layers?
- Which constraints proved most influential?
- How did constraint formalization improve?

### Causal Graph Growth
- How did the causal graph grow over time?
- Which layers expanded most rapidly?
- Which cross-layer connections were most impactful?
- How did graph structure evolve?

### Intervention History
- Which interventions were performed?
- What were their expected vs. observed effects?
- How did interventions update causal understanding?
- Which interventions had unexpected cross-layer effects?

## Archaeological Artifacts

- Causal relationship origin records
- Evidence evolution timelines
- Emergence discovery histories
- Constraint evolution records
- Causal graph growth analysis
- Intervention outcome histories

## Archaeology Structure

Each archaeology artifact contains:

- **Archaeology ID**: Content-addressed identifier
- **Causal Graph IDs**: Graphs being analyzed
- **Question Set**: Archaeological questions being answered
- **Relationship Records**: Retrieved causal relationship origins
- **Evidence Timelines**: Retrieved evidence evolution records
- **Emergence Histories**: Retrieved emergence discovery records
- **Constraint Records**: Retrieved constraint evolution records
- **Graph Growth Analysis**: Retrieved graph evolution records
- **Fingerprint**: Deterministic content hash

## Constraints

- Archaeology must reconstruct complete causal graph evolution
- Archaeology records become constitutional artifacts
- Archaeological analysis preserves causal graph integrity
