# Imagination Metrics

## Purpose

Define metrics for measuring the productivity, quality, diversity, and epistemic integrity of the scientific imagination system.

## Productivity Metrics

### Generation Rate
- Hypotheses generated per time period
- Counterfactuals generated per time period
- Alternative physics models generated
- Engineering concepts generated

### Validation Rate
- Hypotheses entering validation pipeline
- Counterfactuals inspiring experiments
- Engineering concepts prototyped
- Ideas migrating to validated knowledge

## Quality Metrics

### Novelty
- Novel hypothesis ratio
- Truly original counterfactual ratio
- Cross-domain novelty score
- Paradigm-challenging proposal rate

### Scientific Utility
- Hypotheses leading to discoveries
- Counterfactuals improving understanding
- Alternative models informing theory
- Engineering concepts implemented

### Prediction Accuracy
- Hypothesis prediction accuracy
- Counterfactual consequence accuracy
- Alternative model predictive power
- Concept feasibility accuracy

## Diversity Metrics

### Hypothesis Diversity
- Diversity of scientific domains
- Diversity of methodological approaches
- Diversity of assumptions challenged
- Diversity of paradigms explored

### Speculation Diversity
- Distribution across classification levels
- Counterfactual type diversity
- Alternative physics dimension diversity
- Engineering domain diversity

### Cross-Domain Novelty
- Number of cross-domain hypotheses
- Cross-domain counterfactuals
- Interdisciplinary innovation rate
- Domain boundary exploration

## Epistemic Integrity Metrics

### Classification Accuracy
- Classification consistency
- Classification changes over time
- Classification disagreement rate
- Reclassification accuracy

### Separation Integrity
- Knowledge contamination incidents
- Speculation passing as fact incidents
- Classification violations
- Governance interventions

### Validation Success
- Validation pipeline completion rate
- Knowledge migration success rate
- Validation failure analysis
- False positive rate

## Replay and Archaeology Metrics

### Replay Stability
- Imagination replay hash consistency
- Classification replay consistency
- Replay success rate
- Replay completeness

### Archaeology Completeness
- Hypothesis origin record coverage
- Assumption analysis coverage
- Validation path coverage
- Influence tracking coverage

## Readiness Metric

### Scientific Imagination Readiness
- 0.0: Not defined
- 0.2: Counterfactual generation defined
- 0.4: Hypothesis generation specified
- 0.6: Classification specified
- 0.8: Full imagination specified
- 1.0: Complete with replay and archaeology
