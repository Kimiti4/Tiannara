# Discovery Economics Metrics

## Purpose

Define metrics for measuring the efficiency, effectiveness, and health of the resource allocation system.

## Efficiency Metrics

### Resource Utilization
- Compute utilization percentage
- Simulation utilization percentage
- Engineering capacity utilization
- Laboratory utilization
- Observation capacity utilization
- Overall resource utilization

### Discovery Efficiency
- Discoveries per unit compute
- Discoveries per unit simulation
- Discoveries per unit engineering
- Discoveries per unit laboratory resource
- Overall discovery efficiency

### Engineering Efficiency
- Engineering capabilities per unit resource
- Technology readiness per unit resource
- Infrastructure improvement per unit resource
- Innovation rate per unit resource

## Return Metrics

### Scientific Return
- Knowledge gain per resource allocated
- Theory validation per resource
- Knowledge gap reduction per resource
- Cross-domain benefit per resource

### Investment Yield
- Actual vs expected return ratio
- Investment success rate
- Underperforming investment rate
- Risk-adjusted return

### Resource Productivity
- Marginal discovery return
- Resource elasticity of discovery
- Diminishing return threshold
- Optimal allocation proximity

## Health Metrics

### Allocation Fairness
- Gini coefficient of resource distribution
- Domain allocation balance
- Constitutional minimum compliance
- Allocation appeal rate

### Resource Bottleneck Index
- Number of active bottlenecks
- Bottleneck severity
- Bottleneck duration
- Bottleneck resolution rate

### Reserve Health
- Reserve capacity percentage
- Emergency reserve availability
- Strategic reserve utilization
- Reserve replenishment rate

## Stability Metrics

### Replay Stability
- Allocation replay hash consistency
- Investment decision replay consistency
- Replay success rate
- Replay completeness

### Archaeology Completeness
- Archaeology coverage
- Decision record completeness
- Return record completeness
- Evolution record completeness

## Readiness Metric

### Discovery Economics Readiness
- 0.0: Not defined
- 0.2: Resource pools defined
- 0.4: Allocation engine specified
- 0.6: Investment model specified
- 0.8: Full economics specified
- 1.0: Complete with replay and archaeology
