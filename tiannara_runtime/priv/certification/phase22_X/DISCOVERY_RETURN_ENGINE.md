# Discovery Return Engine

## Purpose

Estimate the expected discovery return from resource allocation decisions — quantifying knowledge gain, engineering gain, cross-domain benefit, future discovery multiplier, risk reduction, and civilizational impact.

## Return Dimensions

### Knowledge Gain
- New scientific understanding
- Knowledge gap reduction
- Theory validation or falsification
- Discovery probability and magnitude

### Engineering Gain
- Engineering capability improvement
- Technology readiness advancement
- Infrastructure capability enhancement
- Manufacturing or fabrication improvement

### Cross-Domain Benefit
- Number of domains benefiting
- Benefit magnitude per domain
- Methodology transfer potential
- Instrumentation sharing benefit

### Future Discovery Multiplier
- Downstream discovery enablement
- Follow-on research potential
- New research direction opening
- Bottleneck resolution benefit

### Risk Reduction
- Key uncertainty reduction
- Existential risk contribution
- Decision-relevant uncertainty addressed
- Falsification value (even negative results)

### Civilizational Impact
- Long-term civilizational benefit
- Quality of life improvement
- Resilience enhancement
- Sustainability contribution

## Return Estimation Process

1. **Program Analysis**: Understand program objectives and methodology
2. **Expected Outcome Identification**: Identify likely discoveries
3. **Impact Propagation**: Estimate downstream impacts
4. **Uncertainty Quantification**: Bound return estimates
5. **Confidence Assessment**: Assess confidence in estimates
6. **Return Aggregation**: Combine return dimensions
7. **Documentation**: Record with lineage

## Return Structure

Each return estimate contains:

- **Return ID**: Content-addressed identifier
- **Program ID**: Program being assessed
- **Knowledge Gain**: Expected knowledge gain
- **Engineering Gain**: Expected engineering gain
- **Cross-Domain Benefit**: Cross-domain benefit assessment
- **Multiplier Effect**: Future discovery multiplier
- **Risk Reduction**: Risk reduction quantification
- **Civilizational Impact**: Civilizational benefit estimate
- **Overall Return Score**: Composite return (0.0–1.0)
- **Fingerprint**: Deterministic content hash
