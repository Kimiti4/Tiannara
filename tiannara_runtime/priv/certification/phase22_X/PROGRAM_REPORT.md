# Program Report

## Purpose

Generate comprehensive program governance reports summarizing portfolio state, program health, priority decisions, evolution history, termination records, and recommendations.

## Report Structure

### Executive Summary
- Portfolio overview and key metrics
- Highest and lowest performing programs
- Critical governance decisions pending
- Strategic recommendations

### Portfolio Overview
- Program inventory with domains and status
- Resource allocation distribution
- Portfolio-level risk assessment
- Portfolio diversity analysis

### Program Health Summary
- Health scores per program
- Programs in warning/critical/failing states
- Health trend analysis
- Intervention recommendations

### Priority Assessment
- Current program priority rankings
- Priority change history
- Priority justification summaries
- Reallocation recommendations

### Evolution History
- Recent program evolution operations
- Evolution justifications and approvals
- Impact of evolution on performance
- Pending evolution proposals

### Termination Records
- Recently terminated programs
- Knowledge preserved from termination
- Lessons learned from termination
- Resource released for reallocation

### Interdisciplinary Coordination
- Cross-program dependency status
- Shared resource utilization
- Collaborative milestone status
- Coordination improvement opportunities

### Recommendations
- Priority reallocation recommendations
- Program health intervention suggestions
- Portfolio rebalancing proposals
- Strategic program creation proposals

## Constraints

- Reports must be comprehensive and evidence-driven
- Report records become constitutional artifacts
- Uncertainty is explicitly preserved in all assessments
