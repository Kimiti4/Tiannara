# Discovery Leverage Model

## Purpose

Estimate the downstream discovery leverage of research programs — how many downstream discoveries become possible, how many engineering capabilities unlock, how many domains benefit, how much uncertainty decreases, and how many future programs accelerate.

## Leverage Dimensions

### Downstream Discovery Enablement
- Direct discoveries expected from the program
- Indirect discoveries enabled by program results
- Follow-on research opportunities created
- Discovery chain length and branching

### Engineering Capability Unlock
- New engineering capabilities enabled
- Existing capability improvements
- Bottleneck removal impact
- Engineering platform effects

### Cross-Domain Benefit
- Number of domains receiving direct benefit
- Cross-domain transfer potential
- Methodology diffusion value
- Instrumentation sharing value

### Uncertainty Reduction
- Key uncertainty reduction magnitude
- Decision-relevant uncertainty addressed
- Risk reduction from uncertainty quantification
- Falsification value (even negative results)

### Program Acceleration
- Timeline compression for other programs
- Dependency chain acceleration
- Parallel research path opening
- Synergistic program interactions

## Leverage Estimation Process

1. **Dependency Analysis**: Map downstream dependencies
2. **Impact Propagation**: Estimate impact magnitude per dependency
3. **Network Analysis**: Account for network effects and synergies
4. **Uncertainty Quantification**: Bound leverage estimates
5. **Sensitivity Analysis**: Identify key leverage drivers
6. **Documentation**: Record leverage assessment with lineage

## Leverage Structure

Each leverage assessment contains:

- **Leverage ID**: Content-addressed identifier
- **Program ID**: Program being assessed
- **Downstream Discoveries**: Estimated discoveries enabled
- **Engineering Unlocks**: Capabilities unlocked
- **Cross-Domain Benefit**: Domains benefited
- **Uncertainty Reduction**: Uncertainty decrease estimate
- **Program Acceleration**: Timeline compression estimate
- **Overall Leverage Score**: Composite leverage (0.0–1.0)
- **Fingerprint**: Deterministic content hash

## Constraints

- Leverage estimates are bounded by evidence
- Leverage records become constitutional artifacts
- Leverage estimates updated with new information
