# Concept Merging Engine

## Purpose

Govern the merging of ontology concepts when definitions converge, evidence converges, mathematics is equivalent, or engineering usage overlaps — preserving complete ancestral lineage.

## Merge Triggers

### Definition Convergence
- Two concepts describe the same phenomenon
- Definitions become indistinguishable
- Conceptual boundaries fully overlap

### Evidence Convergence
- Same evidence supports both concepts
- Evidence does not distinguish between concepts
- Combined evidence supports unified concept

### Mathematical Equivalence
- Mathematical formulations shown equivalent
- One concept reducible to another
- Unified mathematical representation exists

### Engineering Usage Overlap
- Engineering systems treat concepts interchangeably
- Practical usage indistinguishable
- Engineering communities converge

## Merge Process

1. **Convergence Assessment**: Evaluate definition, evidence, mathematical, and engineering convergence
2. **Candidate Identification**: Identify concepts for merging
3. **Unified Concept Construction**: Build unified concept with consolidated definition
4. **Evidence Consolidation**: Combine evidence from all merged concepts
5. **Relationship Reconciliation**: Merge and deduplicate relationships
6. **Validation**: Validate unified concept against all evidence
7. **Constitutional Review**: Governance approval
8. **Recording**: Merge recorded with complete lineage

## Merge Structure

Each merge record contains:

- **Merge ID**: Content-addressed identifier
- **Source Concepts**: Concepts being merged
- **Unified Concept**: Resulting unified concept
- **Convergence Basis**: Convergence type
- **Evidence Consolidation**: Evidence combination
- **Definition Reconciliation**: How definitions reconciled
- **Relationship Reconciliation**: Relationship handling
- **Validation Results**: Validation of unified concept
- **Fingerprint**: Deterministic content hash

## Constraints

- Merged concepts preserve all ancestral lineage
- Merge records become constitutional artifacts
- All merges are replayable
