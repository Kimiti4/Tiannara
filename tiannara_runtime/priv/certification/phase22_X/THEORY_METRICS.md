# Theory Ecosystem Metrics

## Purpose

Define metrics for measuring the health, diversity, and performance of the theory ecosystem.

## Diversity Metrics

### Theory Count
- Total number of active theories
- Number of candidate theories
- Number of competing theories
- Number of dominant theories
- Number of specialized theories
- Number of historical theories

### Theoretical Diversity Index
- Diversity of theoretical approaches
- Diversity of mathematical frameworks
- Diversity of assumptions
- Diversity of prediction methods

### Minority Representation
- Number of minority theories preserved
- Minority theory activity level
- Minority theory influence on research
- Minority theory citation frequency

## Performance Metrics

### Prediction Accuracy
- Average prediction accuracy across theories
- Prediction accuracy trend over time
- Best theory prediction accuracy
- Worst theory prediction accuracy

### Engineering Utility
- Engineering systems using each theory
- Engineering reliability per theory
- Engineering innovation per theory
- Practical application breadth

### Competition Health
- Number of active competitions
- Competition participation rate
- Competition outcome diversity
- Competition fairness score

## Evolution Metrics

### Evolution Rate
- Theory revisions per time period
- Theory expansions per time period
- Theory simplifications per time period
- Theory mutations per time period

### Specialization Rate
- Specialization events per time period
- Average specialization depth
- Cross-specialization interaction rate

### Merging Rate
- Merging events per time period
- Successful unification rate
- Post-merge theory stability

## Stability Metrics

### Theory Stability Index
- Average theory lifetime
- Theory revision frequency
- Theory dominance duration
- Prediction volatility

### Replay Stability
- Replay hash consistency
- Replay success rate
- Replay completeness
- Replay performance

### Archaeology Completeness
- Archaeology coverage
- Lineage completeness
- Evidence record completeness
- Competition record completeness

## Readiness Metric

### Theory Ecology Readiness
- 0.0: Not defined
- 0.2: Theory representation defined
- 0.4: Lifecycle defined
- 0.6: Competition engine specified
- 0.8: Full ecosystem specified
- 1.0: Complete with replay and archaeology
