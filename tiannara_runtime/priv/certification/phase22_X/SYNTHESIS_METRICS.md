# Synthesis Metrics

## Purpose

Define quantitative metrics for measuring cross-domain connectivity, relationship density, knowledge transfer rate, unified principle count, scientific and engineering utility, and overall cross-domain synthesis readiness.

## Metrics

| Metric | Description | Target |
|---|---|---|
| Cross-Domain Connectivity | Fraction of domain pairs with active relationships | 0.50 |
| Relationship Density | Average number of relationships per domain | ≥5 |
| Knowledge Transfer Rate | Successful transfers per period | ≥3/period |
| Unified Principle Count | Number of principles unifying ≥2 domains | ≥50 |
| Scientific Utility | Fraction of syntheses producing scientific value | 0.80 |
| Engineering Utility | Fraction of syntheses producing engineering value | 0.70 |
| Replay Stability | Fraction of replays producing identical hashes | 99.9% |
| Archaeology Completeness | Fraction of synthesis history reconstructible | 99% |
| Cross-Domain Readiness | Overall synthesis system maturity index | 0.85+ |

## Target Thresholds

| Metric | Minimum | Target | Excellence |
|---|---|---|---|
| Cross-Domain Connectivity | 0.20 | 0.50 | 0.80 |
| Relationship Density | 2 | 5 | 10 |
| Knowledge Transfer Rate | 1/period | 3/period | 10/period |
| Unified Principle Count | 10 | 50 | 200 |
| Scientific Utility | 0.50 | 0.80 | 0.95 |
| Engineering Utility | 0.40 | 0.70 | 0.90 |
| Replay Stability | 99% | 99.9% | 99.99% |
| Archaeology Completeness | 95% | 99% | 100% |

## Measurement Methodology

- Cross-Domain Connectivity: Domain pairs with relationship / total possible pairs
- Relationship Density: Total relationships / total domains
- Knowledge Transfer Rate: Certified transfers per assessment period
- Unified Principle Count: Principles validated in ≥2 domains
- Scientific Utility: Syntheses leading to scientific publications or discoveries
- Engineering Utility: Syntheses leading to engineering applications

## Constraints

- Metrics must be deterministically computable
- Metric records become constitutional artifacts
