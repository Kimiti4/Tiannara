# Resource Observability Model

## Purpose
Observability for the resource intelligence engine — operators must understand what the engine knows, what decisions it is making, and what the resource situation is.

## Observatory Displays

### Global Resource Inventory
- Total inventory by resource category
- Geographic distribution
- Quality grades
- Change over time

### Resource Flows
- Current flow rates by category
- Flow direction (sources → sinks)
- Flow bottlenecks
- Flow trend visualization

### Critical Shortages
- Resources below safety threshold
- Geographic hotspots
- Projected shortage timeline
- Impact assessment

### Allocation Efficiency
- Allocation vs. demand
- Utilization rates
- Waste indicators
- Equity distribution metrics

### Sustainability Index
- Renewable vs. non-renewable consumption ratio
- Regeneration vs. depletion
- Environmental impact metrics
- Long-term trend

### Strategic Reserves
- Current reserve levels
- Reserve adequacy (days/weeks/months)
- Reserve drawdown history
- Replenishment status

### Forecast Timeline
- Multi-horizon projections
- Scenario comparisons
- Key uncertainty indicators
- Warning signals

### Replay Integrity
- Replay accuracy metrics
- Last verified timestamp
- Coverage of replayable decisions

## Observability Interfaces
- Real-time dashboards
- Structured log streams
- Queryable history
- Alert channels
- Public summary and full detail (by authorization)
