# Resource Report

## Purpose
Generates comprehensive reports on planetary resource status for human decision-makers.

## Report Types

### Global Resource Assessment
- Complete inventory of all planetary resources
- Availability vs. demand for each resource category
- Sustainability indices
- Critical shortage alerts
- Strategic reserve status

### Resource Flow Report
- Energy flow summary
- Material flow analysis
- Water balance
- Food system assessment
- Compute utilization

### Allocation Report
- Current allocations by sector
- Allocation efficiency metrics
- Equity distribution analysis
- Emergency allocation status

### Forecast Report
- Short/medium/long-term projections
- Key uncertainty drivers
- Scenario comparisons
- Warning signals for future constraints

### Resilience Report
- Resource system resilience scores
- Vulnerability assessment
- Strategic reserve adequacy
- Disruption scenario analysis

### Governance Report
- Constitutional compliance of allocations
- Decision audit trail
- Certification status
- Pending decisions

## Report Format
Reports are structured, machine-readable (JSON) with human-readable summaries (Markdown), designed for presentation in the Constitutional Observatory.
