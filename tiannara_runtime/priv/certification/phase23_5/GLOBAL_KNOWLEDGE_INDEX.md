# Global Knowledge Index

## Purpose

Maintain a continuously updated, searchable index of all scientific knowledge
integrated from literature, enabling efficient discovery and cross-referencing
across the entire constitutional knowledge ecosystem.

## Index Structure

| Index | Content |
|-------|---------|
| Publication Index | All processed publications and their metadata |
| Claim Index | All extracted claims, categorized by type and topic |
| Evidence Index | All extracted evidence, linked to claims |
| Citation Index | All citation relationships with context |
| Consensus Index | Current consensus states across topics |
| Gap Index | All identified research gaps |
| Domain Index | Knowledge organized by scientific domain |
| Cross-Reference Index | Links between literature and Tiannara's own discoveries |

## Index Properties

- All indices are deterministically constructed
- Indices are updated as new publications are integrated
- Indices are versioned for replay consistency
- Indices support query for read-only APIs

## Uses

The index supports:
- Efficient retrieval for all CSLIE read-only APIs
- Cross-referencing with other Phase 23 engines
- Observatory visualization queries
- Research gap discovery
- Meta-analysis study identification
