# Consensus Engine

## Purpose

Represent the state of scientific consensus across the literature. Consensus
is derived from evidence, not authority, and never replaces the underlying
evidence.

## Consensus States

| State | Description |
|-------|-------------|
| Strong Consensus | Overwhelming evidence, minimal contradiction |
| Emerging Consensus | Growing evidence, decreasing contradictions |
| Fragmented Consensus | Multiple incompatible lines of evidence |
| No Consensus | Insufficient evidence or irreconcilable disagreement |
| Contested | Active debate with significant evidence on multiple sides |

## Consensus Properties

- Consensus is always backed by citation counts and evidence weights
- Consensus is revisable with new evidence
- Minority views are preserved alongside majority consensus
- Consensus is reported with confidence intervals
- Consensus tracks its evolution over time

## Constitutional Rules

- Consensus never replaces evidence
- Minority views cannot be suppressed by consensus
- Consensus must reference conflicting evidence
- Consensus is always provisional
