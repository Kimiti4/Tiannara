# Literature Synthesis Engine

## Purpose

Produce constitutional syntheses that organize multiple publications into
coherent scientific themes, meta-theories, and research programs.

## Synthesis Hierarchy

```
Individual Papers → Claim Clusters → Evidence Networks →
Scientific Themes → Meta-Theories → Research Programs
```

## Synthesis Outputs

| Level | Description |
|-------|-------------|
| Claim Clusters | Groups of related claims across publications |
| Evidence Networks | Connected evidence supporting a scientific question |
| Scientific Themes | Recurring topics and approaches across papers |
| Meta-Theories | Higher-level theories that subsume multiple findings |
| Research Programs | Organized directions for future investigation |

## Synthesis Properties

- All syntheses preserve links to individual publications
- Syntheses are uncertainty-weighted
- Syntheses can be updated as new publications are acquired
- Syntheses are reviewed by other engines (theory synthesis, knowledge transfer)

## Constitutional Rules

- Syntheses cannot discard contradictory evidence
- Syntheses must represent minority views proportionally
- Syntheses are always provisional
