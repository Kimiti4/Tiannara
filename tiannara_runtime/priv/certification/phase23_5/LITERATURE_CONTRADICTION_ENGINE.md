# Literature Contradiction Engine

## Purpose

Detect, represent, and track contradictions between claims, methods,
assumptions, evidence, and predictions across publications.

## Contradiction Types

| Type | Description |
|------|-------------|
| Conflicting Conclusions | Papers reach opposite conclusions |
| Conflicting Methods | Methods produce incompatible results |
| Conflicting Assumptions | Underlying assumptions contradict |
| Conflicting Evidence | Empirical data contradicts |
| Conflicting Predictions | Predicted outcomes diverge |
| Statistical Conflicts | Effect sizes or significance disagree |

## Contradiction Structure

Each contradiction records:
- Conflicting claim IDs
- Contradiction type
- Supporting evidence for each side
- Publication IDs involved
- Resolution status
- Resolution history
- Uncertainty weights
- Fingerprint (content hash)

## Constitutional Rules

- Contradictions are permanent scientific evidence
- Contradictions cannot be resolved by authority
- Resolution requires new evidence, not publication prestige
- Unresolved contradictions remain visible as open questions
