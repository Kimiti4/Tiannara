# Literature Report

## Purpose

Generate comprehensive reports on the state of scientific literature
integration for observation, analysis, and strategic decision-making.

## Report Types

| Report | Content |
|--------|---------|
| Literature Summary | Publications processed, claims extracted, integration status |
| Citation Landscape | Global citation graph statistics and communities |
| Consensus Report | Current consensus states across major topics |
| Contradiction Map | Open contradictions and their supporting evidence |
| Research Gap Catalog | All identified gaps, prioritized |
| Quality Assessment | Publication quality distributions |
| Credibility Overview | Credibility assignments across domains |
| Integration Report | Knowledge integrated into each target system |
| Trend Analysis | Emerging and declining research areas |
| Literature ROI | Impact of literature on Tiannara's own research |

## Report Properties

- All reports are deterministic (same state → same report)
- Reports include machine-readable and human-readable formats
- Reports are time-stamped and archiveable
- Reports can be generated for any point in the replay timeline
