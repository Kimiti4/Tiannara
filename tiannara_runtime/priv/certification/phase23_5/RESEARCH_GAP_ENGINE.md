# Research Gap Engine

## Purpose

Continuously identify gaps in the scientific literature: missing experiments,
untested assumptions, isolated discoveries, underexplored domains,
cross-domain opportunities, and knowledge bottlenecks.

## Gap Types

| Type | Description |
|------|-------------|
| Missing Experiment | An experiment suggested but not performed |
| Untested Assumption | An implicit assumption never validated |
| Isolated Discovery | A finding not yet replicated or extended |
| Unexplored Domain | A domain with minimal publication coverage |
| Cross-Domain Opportunity | A gap visible only when connecting domains |
| Knowledge Bottleneck | A missing piece blocking further progress |
| Methodological Gap | A needed method that does not exist |
| Replication Gap | A key result not yet independently replicated |

## Gap Structure

Each gap records:
- Gap type
- Description
- Supporting evidence (which publications suggest this gap)
- Estimated impact if filled
- Related claims and publications
- Gap status (open, in_progress, filled, superseded)
- Timestamp

## Uses

Research gaps feed into:
- Scientific question generation (Phase 23.1 CSDR)
- Experiment design (Phase 23.2 ASEO)
- Theory formation (Phase 23.3 CTSE)
- Cross-domain transfer targeting (Phase 23.4 CDKTE)
