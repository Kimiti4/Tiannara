# Meta-Analysis Engine

## Purpose

Perform constitutional statistical synthesis of findings across multiple
studies, preserving variance, bias, sample quality, uncertainty, and
reproducibility.

## Meta-Analysis Inputs

Each study contributes:
- Effect size and confidence interval
- Sample size and characteristics
- Methodology description
- Statistical methods used
- Known biases or limitations
- Reproducibility indicators
- Publication quality score

## Meta-Analysis Outputs

- Pooled effect size with confidence interval
- Heterogeneity measures
- Publication bias assessment
- Subgroup analyses
- Sensitivity analyses
- Quality-adjusted estimates

## Constitutional Requirements

- All methodological choices are documented
- Heterogeneity is reported, not hidden
- Publication bias is explicitly assessed
- Results include uncertainty quantification
- Individual study data remains accessible
