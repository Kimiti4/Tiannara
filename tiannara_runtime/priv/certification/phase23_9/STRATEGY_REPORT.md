# Strategy Report

## Purpose

Generate comprehensive reports on Tiannara's research strategy for observation, analysis, and constitutional oversight.

## Report Types

| Report | Content |
|--------|---------|
| Strategy Summary | Current strategy, active missions, portfolio allocation |
| Grand Challenge Report | Status and progress for each grand challenge |
| Century Roadmap Report | Strategic milestones across all horizons |
| Portfolio Report | Research allocation and balance metrics |
| Unknown Priority Report | Top ranked unknowns with rationale |
| Opportunity Report | Identified scientific opportunities |
| Gap Analysis Report | Research coverage gaps |
| Metrics Report | All scientific civilization metrics |
| Reprioritization Log | History of strategy changes |
| Certification Report | Certification status of all active strategy decisions |

## Report Properties

- All reports are deterministic
- Reports include machine-readable and human-readable formats
- Reports are time-stamped and archiveable
- Reports generated for any point in replay timeline
