# Strategy Certification

## Purpose

Certify that strategic decisions meet constitutional standards before being enacted.

## Certification Checks

| Check | Description |
|-------|-------------|
| Constitutional Alignment | Decision aligns with civilizational constitutional goals |
| Evidence Sufficiency | Sufficient evidence supports the decision |
| Alternative Consideration | Reasonable alternatives were evaluated |
| Impact Assessment | Predicted consequences were assessed |
| Resource Feasibility | Required resources are available |
| Risk Evaluation | Risks were identified and evaluated |
| Explanation Completeness | Decision is fully self-explanatory |

## Certification Level

| Level | Meaning |
|-------|---------|
| Standard | All mandatory checks pass |
| Extended | Additional review of alternatives and impact |
| Constitutional | Highest level, full constitutional council review |

## Certificate Structure

Each certificate records:
- Decision ID
- Certification level
- Per-check results
- Reviewing entity
- Certification timestamp
- Fingerprint (content hash)
