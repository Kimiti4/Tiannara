# Ecosystem Report

## Purpose

Generate comprehensive reports on the state, health, and evolution of the scientific ecosystem.

## Report Sections

### Executive Summary
- Ecosystem health overview
- Key evolution events this generation
- Diversity status
- Notable adaptations

### Institute Registry
- Current institute roster
- Institute evolution history
- Recently formed institutes
- Recently retired institutes

### Collaboration Network
- Network state snapshot
- Recent network changes
- Collaboration density metrics
- Bridge institute identification

### Diversity Profile
- Diversity scores across all dimensions
- Monoculture detection report
- Diversity intervention status
- Diversity trend analysis

### Evolution Events
- Institutional transitions this generation
- Transition type distribution
- Transition success assessment
- Pending evolution proposals

### Knowledge Exchange
- Exchange volume and types
- Cross-institute knowledge flow
- Exchange provenance verification
- Knowledge retention metrics

### Adaptation Status
- Recent adaptation actions
- Adaptation effectiveness
- Pending adaptation proposals
- Constitutional compliance

### Scientific Capital
- Capital distribution report
- Capital flow analysis
- Capital efficiency trends
- Redistribution recommendations

### Ecosystem Health
- Biodiversity index
- Resilience indicators
- Productivity metrics
- Stability assessment

### Replay and Archaeology
- Replay verification timestamp
- Replay pass/fail status
- Archaeology coverage
- Pending archaeology gaps

### Long-Term Trends
- Decade-scale evolution patterns
- Civilization adaptation trajectory
- Resilience trend
- Knowledge frontier expansion

## Report Generation

Reports must be deterministically generated from ecosystem state. No interpretation, no adjustment, no learning. Reports become constitutional artifacts.

## Frequency
- Standard: Per generation
- Comprehensive: Per 10 generations
- Evolution Event: On any institutional transition
