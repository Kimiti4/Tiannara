# Scientific Institution Model (Phase 21.0)

## Purpose

Define the constitutional model for autonomous scientific institutes. Institutes are the primary organizational unit of the research civilization — each is an autonomous constitutional entity governed by a charter and council.

## Institute Lifecycle

```
Chartered → Active → (collaborating) → Frozen → Archived
```

Each institute is chartered by the Scientific Council with a constitutional charter that defines its domain, governance structure, and capital allocation.

## Institute Governance

Each institute has a governance council composed of:
- Institute Director (appointed by Scientific Council)
- Program Leads (elected by program members)
- Domain Experts (appointed by Mathematics/Engineering Councils)

No institute governs itself — all are subject to constitutional oversight.
