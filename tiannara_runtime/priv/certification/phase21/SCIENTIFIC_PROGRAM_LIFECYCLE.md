# Scientific Program Lifecycle (Phase 21.1)

## Purpose

Define the deterministic lifecycle for scientific programs. Every transition requires constitutional evidence.

## Lifecycle Stages

```
Proposal → Evaluation → Approval → Funding → Execution → Expansion → Review → Transition → Retirement → Archive
    ↑                                                                                                    │
    └──────────────────────────────── Iterate ───────────────────────────────────────────────────────────┘
```

## Stage Descriptions

| Stage | Description | Evidence Required |
|-------|-------------|-------------------|
| Proposal | Program defined with scope, questions, impact | Evidence chain, knowledge gaps |
| Evaluation | Deterministic scoring against 10 dimensions | Priority score computation |
| Approval | Council approval decision | Approval record, constitutional check |
| Funding | Capital allocation assigned | Allocation record, capital ledger |
| Execution | Active research, missions, discoveries | Execution replay chain |
| Expansion | Program scope broadening | Expansion proposal, capital increase |
| Review | Periodic evaluation against objectives | Review record, impact assessment |
| Transition | Program succession or completion | Succession plan, closure report |
| Retirement | Program ended | Retirement record, archive deposit |
| Archive | Complete preservation | Archive root, replay root |

## Transition Rules

- Each transition is irreversible (no stage regression)
- Transitions require evidence chains specific to the transition
- Transitions are recorded as content-addressed events
- Archaeology is deposited at each transition

## Review Cycles

Programs are reviewed at fixed generation intervals:
- Short programs: review every 10 generations
- Medium programs: review every 100 generations
- Long-horizon programs: review every 1,000 generations
