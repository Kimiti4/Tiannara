# Future World Model

## Purpose

Define the constitutional representation of a future world — an evidence-grounded projection of civilization's possible state at a specified future time horizon.

## Model Structure

Each future world model contains:
- **Future ID**: Content-addressed identifier
- **Parent Reality Model**: Current reality model used as starting point
- **Time Horizon**: Target generation or date
- **Scientific Assumptions**: Expected discoveries and theory developments
- **Mathematical Assumptions**: Expected formal advances
- **Engineering Assumptions**: Expected capability developments
- **Known Uncertainties**: Explicit uncertainty bounds on all projections
- **Intervention History**: Interventions modeled in this future
- **Confidence Distribution**: Evidence-weighted confidence per domain projection
- **Predicted Outcomes**: Expected state at horizon
- **Risk Profile**: Identified risks within this future
- **Replay Root**: Content-addressed replay identifier
- **Archaeology Root**: Content-addressed archaeology identifier

## Future Generation Process

### Step 1: Baseline Projection
- Extrapolate current reality model forward
- Apply known trends and trajectories
- Document all extrapolation assumptions

### Step 2: Uncertainty Injection
- Identify sources of uncertainty at each horizon
- Compute confidence decay with horizon distance
- Document uncertainty bounds for all projections

### Step 3: Branch Identification
- Identify events that could alter trajectory
- Create branches for each significant event
- Document branching rationale

### Step 4: Confidence Calibration
- Calibrate confidence against historical forecast accuracy
- Apply calibration corrections
- Document calibration methodology

## Horizon-Specific Structure

- Near-term (1–5yr): High resolution, low uncertainty
- Medium-term (5–25yr): Moderate resolution, bounded uncertainty
- Long-term (25–100yr): Directional resolution, high uncertainty
- Century-scale (100–500yr): Visionary resolution, very high uncertainty

## Constraints

- All futures must derive from current reality model
- Assumptions must be explicitly documented
- Uncertainty must increase with horizon distance
- Future models become constitutional artifacts
