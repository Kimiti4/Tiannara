# Interdisciplinary Portfolio Model (Phase 21.1)

## Purpose

Define constitutional collaboration among programs within the portfolio. Shared discoveries, mathematical structures, engineering artifacts, world models, and knowledge graphs must preserve provenance across program boundaries.

## Collaboration Types

| Type | Shared Resource | Provenance Method |
|------|-----------------|-------------------|
| Shared discoveries | Discovery records | Content-addressed with source program ID |
| Shared mathematical structures | Proofs, theorems, expressions | Cross-referenced mathematics registry |
| Shared engineering artifacts | Designs, implementations | Cross-referenced engineering registry |
| Shared world models | Model states, parameters | Versioned world model references |
| Shared knowledge graphs | Knowledge nodes, edges | Cross-referenced knowledge graph entries |

## Collaboration Lifecycle

```
Discovery → Cross-Program Registration
    ↓
    → Program A: Uses in mission
    → Program B: Extends in separate mission
    → Program C: Cites in theory construction
    ↓
Provenance Tracking → Capital Distribution
    ↓
Archaeology Deposit
```

## Capital Distribution for Collaboration

When multiple programs contribute to a shared discovery:
1. Each program's contribution is measured by evidence chain depth
2. Capital is distributed proportionally to contribution
3. The capital distribution is recorded as a replayable artifact
4. All programs receive credit in their capital ledgers

## Cross-Program Dependency Resolution

Programs may depend on discoveries from other programs:
- Dependencies are resolved before program completion
- The dependency graph is content-addressed and acyclic
- Dependency resolution is deterministic and replayable
- Blocked programs are flagged and prioritized
