# Knowledge Growth Model (Phase 21.0)

## Purpose

Define the civilization-wide knowledge growth model. The research civilization tracks all knowledge creation, reuse, compression, and diversification — with the constitutional guarantee that no knowledge may disappear without explanation.

## Knowledge Growth Dimensions

| Dimension | Measurement | Tracking Method |
|-----------|-------------|-----------------|
| New hypotheses | Count per generation | Hypothesis registry |
| New theories | Count per generation | Theory registry |
| New mathematical structures | Count per generation | Mathematics registry |
| New engineering principles | Count per generation | Engineering registry |
| New world models | Count per generation | World model registry |
| Knowledge reuse | Cross-reference count | Citation chain analysis |
| Knowledge compression | Redundancy reduction | Schema consolidation |
| Knowledge diversification | Domain breadth | Domain coverage metrics |

## Knowledge Preservation Guarantee

No knowledge may disappear without constitutional explanation:
- All knowledge is content-addressed and preserved in archaeology
- Knowledge removal requires a documented constitutional process
- Knowledge loss detection triggers automatic investigation
- Knowledge recovery is possible from cold storage
- Knowledge growth is monotonic (never decreases without documented cause)

## Knowledge Growth Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| Knowledge volume | Total content-addressed knowledge entries | Monotonic increase |
| Knowledge diversity | Shannon entropy over domain distribution | ≥ baseline |
| Knowledge reuse rate | Cross-references / total entries | ≥ 0.5 |
| Knowledge compression ratio | Redundant entries eliminated / total | ≤ 0.1 per generation |
| New knowledge rate | New entries per generation | ≥ prior generation |

## Knowledge Graph Integration

All knowledge feeds into the civilization-wide knowledge graph:
- Discoveries create knowledge nodes
- Relationships create knowledge edges
- Evidence chains create provenance paths
- Replay chains create temporal structure
- Archaeology preserves all versions
