# Reality Report

## Purpose

Generate comprehensive reports on the state, consistency, and evolution of the unified reality model.

## Report Sections

- **Executive Summary**: Model status, key integrations, major reconciliations
- **Unified Model Status**: Coverage, consistency, confidence
- **Theory Inventory**: All integrated theories with status
- **Reconciliation Status**: Ongoing and resolved reconciliations
- **Consistency Dashboard**: Scores across all consistency dimensions
- **Contradiction Registry**: Active contradictions and resolution status
- **Cross-Domain Integration**: Recent integration highlights
- **Causal Hierarchy**: Causal chain completeness
- **Unknown Regions**: Documented model gaps
- **Theory Evolution**: Recent theory changes and evidence basis
- **Replay and Archaeology**: Verification status
- **Model Recommendations**: Suggested investigations

## Frequency
- Standard: Per generation
- Comprehensive: Per 10 generations
