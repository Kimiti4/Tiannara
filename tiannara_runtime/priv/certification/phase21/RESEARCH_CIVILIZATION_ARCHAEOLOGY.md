# Research Civilization Archaeology (Phase 21.0)

## Purpose

Define the archaeology model for the research civilization. Civilization archaeology answers the essential questions about why the research civilization evolved as it did.

## Seven Essential Questions

| Question | Answer Source |
|----------|--------------|
| Why was this institute created? | Institute charter, council decision record |
| Why was this program funded? | Program proposal, capital allocation record |
| Why was this mission prioritized? | Priority assignment, dependency analysis |
| Which discoveries resulted? | Discovery records, mission output |
| Which mathematical developments enabled them? | Mathematics references, proof chains |
| Which engineering artifacts emerged? | Engineering artifact references |
| Which future research was unlocked? | Citation chains, dependency resolution |

## Archaeology Artifacts

| Artifact | Content |
|----------|---------|
| Institute charter | Constitutional charter, council approval |
| Program proposal | Evidence chain, scientific questions, impact estimate |
| Mission record | Complete mission execution replay |
| Discovery record | Discovery content, evidence chain |
| Capital ledger | All capital transactions |
| Collaboration record | Cross-domain agreement, contribution tracking |
| Portfolio snapshot | Portfolio state at generation boundary |

## Archaeology Hierarchy

```
Civilization Archaeology Root
    │
    ├── Institute 1 Archaeology
    │   ├── Charter
    │   ├── Program Archaeologies
    │   │   ├── Program 1 → Mission Archaeologies
    │   │   └── Program 2 → Mission Archaeologies
    │   └── Capital records
    │
    ├── Institute 2 Archaeology
    │   └── ...
    │
    ├── Portfolio Archaeology
    │   ├── Allocation records
    │   └── Rebalancing records
    │
    └── Capital Ledger Archaeology
        └── All transactions
```

## Preservation

- All archaeology artifacts are content-addressed
- Archaeology chain is continuous from institute charter to latest discovery
- Archaeology is independently reconstructible from cold storage
- Archaeology preserves every version of every entity
