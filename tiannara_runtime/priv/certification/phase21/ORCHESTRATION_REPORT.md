# Orchestration Report

## Purpose

Generate comprehensive reports on the state and performance of the civilization-scale scientific program orchestration system.

## Report Sections

### Executive Summary
- Total active programs and missions
- Resource utilization overview
- Civilization productivity summary
- Key bottlenecks and issues

### Program Portfolio Status
- Active programs by domain
- Program health assessment
- Program progress against milestones
- Program dependency status

### Mission Coordination Status
- Active missions by coordination mechanism
- Mission lifecycle distribution
- Blocked missions and causes
- Recently completed missions

### Schedule Report
- Current schedule snapshot
- Schedule adherence metrics
- Upcoming schedule allocation
- Preemption and delay report

### Resource Allocation
- Current allocation by resource type
- Utilization by institute
- Resource contention areas
- Starvation prevention status

### Dependency Management
- Dependency graph statistics
- Critical path analysis
- Bottleneck identification
- Resolution progress

### Cross-Domain Coordination
- Active collaborations
- Cross-domain discovery report
- Institute coordination summary
- Interdisciplinary impact

### Synchronization Events
- Recent synchronizations
- Pending synchronization requests
- Synchronization conflicts (if any)
- Provenance verification status

### Execution Balancing
- Imbalance detection report
- Recent balancing actions
- Balancing impact assessment
- Outstanding balance concerns

### Replay and Archaeology
- Replay verification timestamp
- Replay pass/fail status
- Archaeology coverage
- Pending archaeology gaps

### Constitutional Compliance
- Orchestration compliance verification
- Constitutional violation report (if any)
- Pending constitutional review items
- Compliance trend

## Report Generation

Reports must be deterministically generated from current orchestration state. No interpretation, no adjustment, no learning. Reports become constitutional artifacts and must be replayable.

## Frequency
- Standard: Per generation
- Comprehensive: Per 10 generations
- Crisis: On imbalance detection or constitutional violation
