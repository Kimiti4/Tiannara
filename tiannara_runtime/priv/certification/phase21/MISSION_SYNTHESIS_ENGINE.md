# Mission Synthesis Engine

## Purpose

Transform scientific opportunities into fully specified constitutional research missions through deterministic synthesis processes.

## Inputs

- Scientific opportunity (from Phase 21.2)
- Mission template library
- Constitutional constraints
- Domain-specific mission patterns

## Process

### Step 1: Opportunity Interpretation
- Parse opportunity specification
- Extract scientific question
- Identify knowledge gap type
- Map domains to mission categories

### Step 2: Mission Structure Generation
- Apply constitutional mission template
- Generate mission ID (content-addressed)
- Formulate research objective statement
- Define expected knowledge gain
- Set initial mission parameters

### Step 3: Mathematical Foundation Assignment
- Identify required mathematical structures
- Map to existing mathematical knowledge
- Specify mathematical dependencies
- Document assumed mathematical results

### Step 4: Engineering Requirement Identification
- Determine engineering infrastructure needs
- Specify experimental equipment requirements
- Identify simulation platform needs
- Document measurement instrument requirements

### Step 5: Deliverable Specification
- Define expected outputs
- Specify knowledge artifacts
- Identify potential engineering artifacts
- Document expected publications or reports

### Step 6: Constitutional Compliance Check
- Verify mission aligns with constitutional principles
- Confirm evidence basis for mission
- Validate deterministic construction
- Ensure replay and archaeology roots set

## Outputs

- Complete mission specification
- Mission ID
- Root dependencies
- Replay hash chain fragment
- Archaeology record seed

## Determinism

All synthesis steps must produce identical results given identical inputs. No randomness, no learning, no optimization.

## Constraints

- Every mission must have exactly one originating opportunity
- Every mission must have at least one mathematical dependency
- Every mission must have at least one validation criterion
- Mission IDs must be content-addressed from full mission specification
- No mission may be empty or have undefined parameters
