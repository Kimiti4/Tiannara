# Mission Generation Report

## Purpose

Generate comprehensive reports on the state and performance of the autonomous research mission generation system, providing visibility into mission production, quality, and constitutional compliance.

## Report Sections

### Executive Summary
- Total missions generated
- Active missions
- Programs under construction
- Mission readiness overview
- Key metrics summary

### Mission Portfolio Overview
- Mission count by domain
- Mission count by program type
- Mission lifecycle distribution
- Feasibility distribution
- Dependency complexity distribution

### Cross-Domain Activity
- Cross-domain mission count
- Collaboration type distribution
- Domain pair analysis
- Interdisciplinary impact assessment

### Feasibility Analysis
- Feasibility score distribution
- Low-feasibility mission list
- High-feasibility mission highlights
- Feasibility improvement trends

### Validation Coverage
- Missions with complete validation plans
- Missions with partial validation
- Missions lacking validation plans
- Validation quality distribution

### Program Construction
- Programs under construction
- Programs completed
- Program type distribution
- Program dependency structures

### Dependency Analysis
- Dependency graph statistics
- Critical path analysis
- Dependency resolution status
- Resolved vs. unresolved dependencies

### Replay Verification
- Most recent replay timestamp
- Replay pass rate
- Hash match percentage
- Replay failure details (if any)

### Archaeology Status
- Complete archaeology records
- Archaeology gaps
- Reconstruction verification status

### Constitutional Compliance
- Missions passing constitutional review
- Missions pending review
- Missions requiring restructuring
- Compliance violation report

## Report Generation

Reports must be deterministically generated from current system state. No interpretation, no adjustment, no learning. Reports become constitutional artifacts and must be replayable.

## Frequency

- Standard: Per generation
- Comprehensive: Per 10 generations
- Audit: On demand by constitutional authority
