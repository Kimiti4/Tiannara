# Research Civilization Runtime (Phase 21.0)

## Purpose

Define the runtime architecture for the autonomous research civilization. The runtime manages institutes, programs, missions, portfolios, and scientific capital as constitutional entities within the CSOS.

## Runtime Architecture

```
CSOS v1.0 Foundation
    │
    ├── Cognitive Runtime (Phase 18)
    ├── Civilizational Runtime (Phase 19)
    ├── Constitutional Runtime (Phase 20)
    │
    v
CARC Runtime (Phase 21)
    │
    ├── Institute Manager
    │   └── Institute lifecycle, charter enforcement, council management
    │
    ├── Program Manager
    │   └── Program lifecycle, priority scheduling, dependency resolution
    │
    ├── Mission Manager
    │   └── Mission lifecycle, execution, validation, integration
    │
    ├── Portfolio Manager
    │   └── Portfolio categorization, allocation, rebalancing
    │
    ├── Capital Manager
    │   └── Capital accounting, allocation, reinvestment
    │
    ├── Collaboration Manager
    │   └── Cross-domain collaboration, provenance tracking
    │
    └── Knowledge Growth Tracker
        └── Civilization-wide knowledge metrics
```

## Runtime Properties

- All managers operate deterministically from CSOS evidence
- Manager state is content-addressed and replayable
- Each manager produces archaeology deposits
- Managers coordinate via constitutional contracts
- Runtime evolution follows CSOS generation lifecycle

## CSOS Integration

The CARC runtime extends CSOS via the Extension Framework:
- All extensions use CSOS replay contracts
- All extensions use CSOS archaeology contracts
- All extensions use CSOS certification process
- The foundational baseline (CSOS 1.0) is never modified
