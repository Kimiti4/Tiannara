# Opportunity Archaeology Model

## Purpose

Define the archaeological framework for reconstructing the reasoning, evidence, and decisions behind every scientific opportunity, enabling future civilizations to understand the frontier evolution.

## Archaeological Questions

### Discovery Questions
- Why was this opportunity discovered?
- Which evidence revealed the knowledge gap?
- Which discovery mechanism identified it?
- What was the frontier state at discovery?

### Motivation Questions
- Which contradictions motivated this opportunity?
- What theoretical tensions created the gap?
- Which unexplained observations contributed?
- What engineering limitations drove it?

### Domain Questions
- Which domains contributed to the opportunity?
- What was each domain's specific contribution?
- Were there cross-domain tensions?
- How did domains interact in the gap?

### Prioritization Questions
- Why was this opportunity prioritized?
- What were the dimension scores?
- How did it rank against competing opportunities?
- Was there any constitutional override?

### Impact Questions
- Which future discoveries resulted from this opportunity?
- How did the frontier evolve after closure?
- What derivative opportunities emerged?
- What was the actual information gain vs expected?

### Frontier Evolution Questions
- How did the knowledge frontier evolve?
- Which frontier layers advanced?
- Were new frontier regions revealed?
- What unknown unknowns became known?

## Archaeological Record Structure

Every opportunity archaeology record contains:
1. Opportunity ID and generation context
2. Discovery mechanism and evidence chain
3. Frontier snapshot before opportunity identification
4. Priority dimension scores and rationale
5. Lifecycle transition history
6. Portfolio integration outcome
7. Actual discovery results (when completed)
8. Frontier snapshot after opportunity closure

## Independent Reconstruction

Opportunity archaeology must be independently reconstructible from cold storage:
- All reasoning derivable from deterministic processes
- Rationale reconstructible from inputs and parameters
- Contradictions between expected and actual outcomes flagged

## Constraints

- Every opportunity must have a complete archaeology record
- Archaeology must answer all defined questions
- Records must be independently reconstructible
- All opportunity decisions must have documented rationale
- Archaeology must span opportunity discovery through impact
