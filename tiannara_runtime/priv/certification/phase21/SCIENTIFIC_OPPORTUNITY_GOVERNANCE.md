# Scientific Opportunity Governance

## Purpose

Define the constitutional governance framework for scientific opportunity management, ensuring every opportunity undergoes evidence-based review before entering the research portfolio.

## Governance Lifecycle

### Stage 1: Identification
- Opportunity detected by discovery engine
- Initial characterization recorded
- Discovery mechanism documented
- Identification timestamp (deterministic)

### Stage 2: Verification
- Independent verification of frontier gap
- Evidence sufficiency assessment
- Gap reality confirmation
- Verification by at least 2 independent mechanisms

### Stage 3: Ranking
- Apply prioritization dimensions
- Compute composite priority score
- Assign priority classification
- Record all dimension scores

### Stage 4: Portfolio Integration
- Submit opportunity to portfolio governance (Phase 21.1)
- Portfolio balance assessment
- Resource requirement estimation
- Program alignment verification

### Stage 5: Mission Proposal
- If accepted by portfolio, trigger mission generation (Phase 21.3)
- Initial mission scope definition
- Success criteria proposal
- Resource envelope estimation

### Stage 6: Research Scheduling
- Opportunity queued for scheduling (Phase 21.4)
- Dependency resolution initiation
- Resource allocation planning
- Timeline estimation

## Governance Principles

- Governance determines priority, not truth
- Scientific truth is determined by evidence, not governance
- Every opportunity receives fair evaluation
- Governance decisions are appealable within constitutional bounds
- All governance actions are deterministic and replayable

## Constitutional Constraints

- Governance must be evidence-based
- No opportunity may be suppressed without evidence
- Rankings must be transparent and deterministic
- Governance records become constitutional artifacts
- Human constitutional authority may override rankings
