# Opportunity Report

## Purpose

Generate comprehensive reports on the state and performance of the scientific opportunity management system, providing visibility into frontier evolution, opportunity discovery, and knowledge gap status.

## Report Sections

### Executive Summary
- Total opportunities identified
- Frontier size and growth
- High-priority opportunities
- Key discoveries from completed opportunities

### Knowledge Frontier Status
- Frontier layer breakdown
- Frontier growth rate
- Layer transition events
- Frontier health indicators

### Opportunity Discovery
- New opportunities this generation
- Discovery mechanism distribution
- Domain distribution
- Cross-domain opportunity highlights

### Priority Ranking
- Current opportunity ranking
- Priority tier distribution
- Recently promoted opportunities
- Recently demoted opportunities

### Information Gain Analysis
- Gain distribution across opportunities
- High-gain opportunity details
- Gain estimate confidence analysis
- Expected vs actual gain tracking

### Cross-Domain Activity
- Active cross-domain opportunities
- Domain pair analysis
- Cross-domain discovery highlights
- Domain boundary tension report

### Frontier Progress
- Gaps closed this generation
- Frontier advancement metrics
- Layer migration events
- Remaining gap severity

### Opportunity Lifecycle
- Lifecycle distribution
- Bottleneck stages
- Average lifecycle duration
- Stalled opportunity report

### Replay and Archaeology
- Replay verification timestamp
- Replay pass/fail status
- Archaeology coverage
- Pending archaeology gaps

### Constitutional Compliance
- Governance compliance verification
- Priority fairness audit
- Evidence sufficiency check
- Constitutional violation report (if any)

## Report Generation

Reports must be deterministically generated from opportunity system state. No interpretation, no adjustment, no learning.

## Frequency
- Standard: Per generation
- Comprehensive: Per 10 generations
- Frontier Event: On significant frontier transitions
