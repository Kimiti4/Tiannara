# Forecast Updating Engine

## Purpose

Update forecasts deterministically based on new evidence, ensuring all prediction revisions are evidence-driven and fully documented.

## Update Triggers

The only valid triggers for forecast updates:
- **New Observations**: Empirical data that constrains projections
- **Validated Experiments**: Reproducible experimental results
- **Mathematical Proofs**: Formal proofs that resolve uncertainty
- **Theory Revisions**: Evidence-based theory modifications
- **Engineering Validation**: Demonstrated engineering capabilities
- **External Data**: Astronomical, geophysical, or global monitoring data

## Update Process

### Step 1: Evidence Intake
- Receive and validate new evidence
- Verify evidence integrity and provenance
- Classify evidence impact on current forecasts

### Step 2: Impact Assessment
- Determine which futures are affected
- Quantity change in confidence distributions
- Identify new branching opportunities

### Step 3: Forecast Revision
- Apply evidence to affected futures
- Update confidence distributions
- Create new branches if warranted
- Document all changes with evidence linkage

### Step 4: Calibration
- Compare updated forecasts against actual outcomes
- Measure and apply calibration corrections
- Track forecast accuracy metrics

## Prohibited Update Sources

- Heuristic preference
- Wishful thinking
- Political considerations
- Institutional bias
- Personal authority
- Unsupported speculation

## Constraints

- Updates must be evidence-only
- All update rationales must be documented
- Forecast revision history must be replayable
- Update records become constitutional artifacts
