# Trust Engine

## Purpose

Represent trust in participants based on reproducibility, scientific rigor, constitutional compliance, historical reliability, and review quality. Trust never substitutes for evidence.

## Trust Factors

| Factor | Basis |
|--------|-------|
| Reproducibility | Track record of reproducible results |
| Scientific Rigor | Methodological quality of past work |
| Constitutional Compliance | Adherence to constitutional rules |
| Historical Reliability | Consistency and honesty over time |
| Review Quality | Constructiveness and accuracy of reviews |

## Trust Properties

- Trust is multi-dimensional, not a single score
- Trust is evidence-based, not subjective
- Trust is revisable with new evidence
- Trust is transparent — contributors can see their trust profile
- Trust never substitutes for evidence in scientific evaluation

## Constitutional Rules

- Trust cannot be used to bypass evidence requirements
- Low-trust participants can still contribute
- Trust is independently verifiable
- Trust discrimination is constitutionally prohibited
