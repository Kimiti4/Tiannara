# Task Coordination Engine

## Purpose

Allocate research tasks among team members deterministically and constitutionally. Tasks include research questions, hypotheses, experiments, simulations, engineering validation, peer review, theory synthesis, and cross-domain transfer.

## Task Types

| Type | Description |
|------|-------------|
| Research Questions | Formulating questions to investigate |
| Hypotheses | Generating testable hypotheses |
| Experiments | Designing and conducting experiments |
| Simulations | Running and analyzing simulations |
| Engineering Validation | Testing engineering implementations |
| Peer Review | Reviewing team outputs |
| Theory Synthesis | Integrating findings into theories |
| Cross-Domain Transfer | Applying knowledge across domains |

## Allocation Process

1. Decompose research problem into tasks
2. Map tasks to required capabilities
3. Match tasks to participant capabilities and availability
4. Assign tasks deterministically
5. Record task allocation with justification

## Constitutional Rules

- Task allocation is deterministic and explainable
- Allocation considers participant preferences when possible
- Allocation is revisable with team consent
- Unassigned tasks return to the pool
