# Collaborative Consensus Engine

## Purpose

Represent consensus among collaboration participants. Supports unanimous agreement, majority agreement, weighted agreement, expert agreement, no consensus, and minority positions.

## Consensus States

| State | Meaning |
|-------|---------|
| Unanimous | All participants agree |
| Majority | Most participants agree |
| Weighted | Agreement weighted by expertise/reputation |
| Expert | Agreement among domain experts |
| No Consensus | No agreement possible |
| Minority Position | Documented minority views |

## Consensus Process

1. Collect positions from all participants
2. Determine agreement level
3. Identify consensus state
4. Record minority positions
5. Certify consensus outcome

## Constitutional Rules

- Consensus never suppresses minority positions
- Minority positions are permanently preserved
- Consensus state is transparent and explainable
- Consensus is revisable with new evidence
