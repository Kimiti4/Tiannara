# Attribution Engine

## Purpose

Assign permanent constitutional attribution for every scientific contribution. Supports individual, group, institutional, multi-agent, and shared discovery attribution.

## Attribution Types

| Type | Description |
|------|-------------|
| Individual | Single person or agent |
| Group | Named research group |
| Institution | University, lab, or organization |
| Multi-Agent | Multiple autonomous agents |
| Shared Discovery | Simultaneous independent discovery |

## Attribution Properties

- Attribution is permanent and immutable
- Attribution is proportional to contribution
- Attribution is independently verifiable
- Attribution cannot be retroactively removed
- Attribution is fully replayable

## Constitutional Rules

- All contributors must be attributed
- Attribution cannot be waived or transferred
- Disputed attributions are resolved constitutionally
- Attribution is part of the archaeological record
