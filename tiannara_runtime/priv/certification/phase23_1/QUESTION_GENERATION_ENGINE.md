# Question Generation Engine

## Purpose

The Question Generation Engine continuously generates scientific questions from observations, knowledge gaps, contradictions, and prediction failures. Questions become first-class scientific artifacts with full provenance, priority, and lifecycle management.

## Question Sources

| Source | Description |
|--------|-------------|
| Knowledge Gaps | Explicitly registered areas of unknown knowledge |
| Contradictions | Conflicting evidence or observations |
| Missing Causal Links | Observed phenomena without known mechanisms |
| Prediction Failures | Predictions that did not match observations |
| Engineering Bottlenecks | Engineering problems requiring scientific investigation |
| Unexplained Observations | Observations without any hypothesis |
| Theory Conflicts | Competing theories making different predictions |
| Anomaly Patterns | Statistical outliers in observation streams |

## Question Structure

```
ScientificQuestion {
  question_id: content-addressed,
  text: string,
  source_observations: [observation_id],
  domain: string,
  knowledge_gap_refs: [knowledge_gap_id],
  priority_score: float,
  status: :open | :investigating | :answered | :obsolete | :abandoned,
  hypotheses_generated: [hypothesis_id],
  confidence: float,
  created_at: integer,
  question_hash: string
}
```

## Question Lifecycle

```
Generation → Prioritization → Hypothesis Assignment → Investigation → Resolution → Archival
```

### Generation
Questions are generated by the engine based on configured sources. Each question includes its source observations for full provenance.

### Prioritization
Questions are scored on: novelty, impact, feasibility, urgency, cross-domain relevance, constitutional alignment.

### Hypothesis Assignment
High-priority questions are assigned to the Hypothesis Generation Engine for hypothesis proposal.

### Investigation
Active questions drive the discovery pipeline until resolved.

### Resolution
Questions are resolved when: answered by evidence, rendered obsolete, or abandoned after sufficient unsuccessful investigation.

## Constitutional Guarantees

- Every question traces to its source observations
- No question is silently discarded
- Abandoned questions are archived, not deleted
- Question evolution is replayable
