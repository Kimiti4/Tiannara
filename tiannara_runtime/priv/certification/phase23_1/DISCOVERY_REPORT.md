## Executive Summary

The Constitutional Scientific Discovery Runtime (CSDR) has been designed and architected as Tiannara's autonomous scientific discovery engine. The CSDR transforms Tiannara from possessing scientific infrastructure into a continuously operating scientific researcher.

The CSDR architecture includes:
- **18 architecture documents** defining all aspects of scientific discovery
- **8 JSON schemas** defining all data structures
- **Complete discovery pipeline** from observation to knowledge integration
- **Full provenance tracking** across all discovery artifacts
- **Explicit uncertainty representation** for all knowledge
- **Theory evolution** with birth, growth, competition, merge, split, replacement, retirement
- **Replay and archaeology** for all discovery decisions
- **Certification** ensuring constitutional compliance
