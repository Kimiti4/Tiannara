# Process Selection Engine

## Purpose

Select optimal manufacturing processes for each engineering artifact. Every process selection is explainable and traceable.

## Supported Processes

| Category | Processes |
|----------|-----------|
| Subtractive | Machining, drilling, grinding, EDM |
| Formative | Casting, forging, stamping, injection molding |
| Additive | FDM, SLS, SLA, DMLS, binder jetting |
| Assembly | Welding, fastening, adhesive bonding, press fit |
| Electronics | PCB fabrication, soldering, wire bonding |
| Semiconductor | Lithography, etching, deposition, doping |
| Composite | Layup, filament winding, pultrusion |
| Future | Emerging manufacturing technologies |

## Selection Criteria

| Criterion | Description |
|-----------|-------------|
| Geometry | Can the process produce the required geometry? |
| Tolerance | Can the process hold required tolerances? |
| Material | Is the process compatible with the material? |
| Volume | Is the process economical at required volume? |
| Quality | Can the process achieve required quality? |
| Cost | Is the process cost-effective? |
| Lead Time | Can the process meet schedule? |
| Sustainability | What is the environmental impact? |
