# Industrial Capability Engine

## Purpose

Assess the capabilities of industrial ecosystems to determine where manufacturing should occur.

## Capability Dimensions

| Dimension | Description |
|-----------|-------------|
| Process Capability | Which manufacturing processes are available? |
| Capacity | What production volume is possible? |
| Quality History | What is the track record of quality? |
| Automation Level | What level of automation exists? |
| Skilled Labor | What workforce capabilities exist? |
| Certification Status | What certifications does the facility hold? |
| Technology Currency | How modern is the equipment? |
| Adjacent Capabilities | What other capabilities exist nearby? |

## Capability Assessment

- Each dimension is scored with evidence
- Overall capability index is computed
- Capability gaps are identified and documented
- Capability growth over time is tracked
- Multiple facilities can be compared
