# Industrial Observability Model

## Purpose

Provide full observability into the manufacturing ecosystem. Integrate with the Tiannara Observatory.

## Observable Metrics

| Metric | Description |
|--------|-------------|
| Manufacturing Readiness | Overall readiness level across products |
| Factory Network | All active factories, status, capacity |
| Supply Chain Graph | Supplier relationships, dependencies |
| Quality Metrics | Yield, defect rates, CPK |
| Production Capacity | Current utilization, available capacity |
| Industrial Risks | Active risks, severity, mitigation status |
| Resource Utilization | Material, equipment, labor usage |
| Sustainability | Energy, carbon, waste metrics |
| Manufacturing Health | Overall manufacturing ecosystem health |
