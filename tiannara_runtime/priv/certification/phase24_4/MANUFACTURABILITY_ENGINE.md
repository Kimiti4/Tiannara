# Manufacturability Engine

## Purpose

Evaluate engineering designs for manufacturability. Every result is explainable and actionable.

## Evaluation Dimensions

| Dimension | Questions |
|-----------|-----------|
| Geometry | Can the geometry be produced? Are there undercuts, thin walls, sharp corners? |
| Tolerance | Can tolerances be held? Are tolerances unnecessarily tight? |
| Assembly | Can parts be assembled? Is there access for tools? |
| Materials | Are materials available and process-compatible? |
| Tooling | Is specialized tooling required? Is it available? |
| Automation | Can the process be automated? |
| Inspection | Can quality be inspected? Is there access for measurement? |
| Maintainability | Can the product be maintained in the field? |
| Repairability | Can the product be repaired? |
| Recyclability | Can materials be recovered at end of life? |

## Manufacturability Score

Each dimension produces a score (0-1) with supporting evidence. An overall manufacturability index is computed. Scores below threshold trigger design recommendations.
