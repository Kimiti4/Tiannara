# Subsystem Allocation Engine

## Purpose

Allocate functions to specific engineering subsystems. Allocation remains evidence-backed and constitutionally governed.

## Allocation Targets

| Target | Description |
|--------|-------------|
| Mechanical Systems | Structures, mechanisms, kinematics |
| Electrical Systems | Power, wiring, distribution |
| Electronics | Circuitry, sensors, actuators |
| Software | Algorithms, logic, control |
| AI | Learning, reasoning, autonomy |
| Robotics | Manipulation, mobility, perception |
| Communications | Data links, protocols, networks |
| Energy | Generation, storage, conversion |
| Control | Feedback, regulation, automation |
| Human Interfaces | Displays, controls, ergonomics |

## Allocation Properties

- Each allocation traces to specific functions
- Allocation rationale is recorded
- Alternative allocations are maintained
- Allocation conflicts are identified and resolved constitutionally
- Allocation coverage is continuously assessed
