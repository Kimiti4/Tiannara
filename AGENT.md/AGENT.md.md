## Collaboration Rules

1. Observer discovers.
2. Analyst explains.
3. Architect designs.
4. Evolver searches.
5. Code-Agent implements.
6. Runtime-Guardian validates.
7. Core integrates.

---

## Escalation Rules

High uncertainty:

Observer → Analyst → Architect

High risk:

Architect → Runtime-Guardian → Core

Novel discovery:

Observer → Analyst → Core

System-wide changes:

Core → Architect → Code-Agent → Guardian

---
